# X-Stage Karaoke PC — เกณฑ์ตรวจรับทุกเมนูและตัวติดตั้ง

โครงการ: webbase-x/xstage · Windows x64 · XStageKaraoke.exe

หลักการ: ห้ามนับว่า "ผ่าน" เพราะไฟล์ Build สำเร็จหรือเมนูแสดงบนจอ ต้องแยกทดสอบการเชื่อมคำสั่ง ทดสอบไฟล์หลังติดตั้ง และทดสอบพฤติกรรมบน Windows/อุปกรณ์จริง

## ระดับการยืนยัน

- A — อัตโนมัติจาก Source: python tools/run_build_tests.py และ tests/test_context_menu.py, tests/test_installer_runtime_menus.py ตรวจ callback และสถานะ โดยไม่ใช้อุปกรณ์จริง
- B — Windows Runner: .github/workflows/build-windows-pc.yml ทำ Silent Install ไปยังพาธมีช่องว่างและภาษาไทย แล้วตรวจ EXE, DLL x64, เครื่องมือซ่อม และ --check-dependencies จากโฟลเดอร์ที่ติดตั้ง
- C — เครื่อง Windows จริง: ต้องทดสอบกับจอ ลำโพง ไมค์/การ์ดเสียง และเครือข่ายตามกรณีจริง บันทึกหลักฐานและผลจริง ไม่อ้างว่าอัตโนมัติครอบคลุมส่วนนี้

## Checklist ตรวจเมนูจริง (ระดับ C)

## เกณฑ์ผ่านก่อนเผยแพร่

- A: ต้องมีผล build-tests-summary.json ที่ pass=true ไม่มี failures/errors และตรวจสอบเหตุผลของ skipped
- B: ต้องมีผล Silent Install + Runtime Check หลังติดตั้งจริงบน Windows Runner
- C: ต้องบันทึกวัน เครื่อง รุ่น Windows อุปกรณ์ ชนิดไฟล์ตัวอย่าง ขั้นตอน ผลจริง และภาพ/Log; กรณียังไม่ได้ทดสอบให้เขียน "ยังไม่ได้ทดสอบ" ไม่ใช่ "ผ่าน"
- Release: ห้ามตั้ง windows-pc-latest.json.available=true หรือประกาศ "สมบูรณ์" หาก A/B ไม่ผ่าน หรือไม่มีหลักฐาน C สำหรับเล่น MIDI+SoundFont, WAV/MP3, คิว, ภาพ/เนื้อร้อง, ความเสถียร และถอนติดตั้ง/อัปเดต

ตรวจผลอัตโนมัติ: GitHub Actions → build-windows-pc.yml → build-tests-summary.json/build-tests.log และขั้นตอน Install candidate silently and verify installed runtime.
