# X-Stage Karaoke 0.5.74

- เมนูคลิกขวา → เครื่องมือ → ตรวจและซ่อมส่วนประกอบ: ตรวจในโปรเซสแยก ไม่เล่นเสียงและไม่หยุดเพลงระหว่างตรวจ
- ปุ่ม “ปิดโปรแกรมแล้วซ่อม” บันทึกการตั้งค่า/คิว ปิดโปรแกรม รอโปรเซสเดิมออกก่อนซ่อม แล้วเปิดใหม่เมื่อผ่านการตรวจ หากปิดไม่ได้ภายใน 120 วินาทีจะยกเลิกโดยไม่บังคับปิด
- รองรับ Windows 10/11 x64; การซ่อมตรวจ BASS/BASSMIDI/BASS FX และ Visual C++ runtime ส่วนซอร์สตรวจ/ติดตั้ง Python dependencies ด้วย ไม่ได้ติดตั้งไดรเวอร์หรือ SoundFont ของผู้ใช้
- ถ้าโมดูลภายใน EXE ขาด ต้องสร้างหรือติดตั้งจากชุดครบชุดใหม่ การซ่อมจะรายงานไม่สำเร็จ ไม่แสดงว่าพร้อมทั้งที่ตรวจไม่ผ่าน
- ไฟล์ดาวน์โหลดในแคชที่เสียจะดาวน์โหลดใหม่อัตโนมัติ ไฟล์ offline ที่เสียเก็บต้นฉบับไว้แล้วดาวน์โหลดแทน ตรวจ ZIP/x64 PE และลายเซ็นผู้เผยแพร่สำหรับตัวติดตั้งก่อนใช้
- สถานะ EQ แยก “ไม่รองรับ”, “ยังไม่ได้ใช้”, “ยังไม่บันทึกประจำเพลง” และ “บันทึกประจำเพลงแล้ว” ตามสถานะตัวประมวลผลจริง
- “ชดเชยพรีเซ็ต” ใช้ตอนเลือกพรีเซ็ต/ความเข้ม ส่วนการลากแถบเองไม่ลด Input อัตโนมัติ ใช้ปุ่ม “เผื่อระดับเสียง” เมื่อพร้อม ค่านี้เป็นคำแนะนำจากกราฟ ไม่ใช่ Limiter
- “จัดการค่าเพลง” เลือกค่าเดิมแล้วชี้ไฟล์ตำแหน่งใหม่ได้ ไม่เดาเพลงจากชื่อ หากปลายทางมีค่าเดิมจะถามก่อนแทนที่ ค่าที่เล่นอยู่ไม่เปลี่ยนกะทันหัน; ใช้ค่าใหม่เมื่อเรียกเพลงครั้งถัดไป
- หน้าต่าง EQ ตรวจขอบเขตพื้นที่จอเมื่อเปิด/ลากและเป็นระยะ เพื่อดึงกลับเมื่อเปลี่ยนจอ ไม่ใช้ตำแหน่งนอกพื้นที่ทำงาน
- EQ ปรับเพลง X-Stage ที่ใช้ BASS; มิเตอร์ยังวัดเสียงรวม Windows ของอุปกรณ์ที่เลือก

ข้อจำกัดการตรวจรุ่นนี้: ทดสอบตรรกะและ Tk บน Linux ด้วยตัวแทน native audio เท่านั้น ยังไม่ได้ทดสอบเสียงจริง, Windows DPI/UAC, จอหลายจอจริง หรือสร้าง EXE บน Windows
