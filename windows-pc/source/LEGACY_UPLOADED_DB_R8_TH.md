# X-Stage Karaoke Windows — Build Gate Fix + DB Recovery R8

## เพลงที่อัปโหลดไว้ในรุ่นก่อน จะอัปเดตฐาน DB อย่างไร

**ไม่ต้องสร้าง `songs.sqlite3` ใหม่ และห้ามลบไฟล์เพลงบน Google Drive**

ฐานเพลงในเครื่อง `Data/songs.sqlite3` ใช้เก็บข้อมูลเพลงท้องถิ่น ส่วนฐานสำหรับเว็บไซต์อยู่ใน Google Drive ส่วนตัวใต้ `XStageWeb`:

- `XStageWeb/current.json` ชี้ไปยังฐานเพลงรุ่นที่เผยแพร่แล้ว
- `XStageWeb/catalogs/database-<generation>.json` เป็นรายการเพลงที่เว็บไซต์อ่านได้
- `XStageWeb/catalogs/delta-<generation>.json` เป็นข้อมูลเพิ่ม/ปรับรุ่นระหว่างซิงค์ (ถ้ามี)
- `XStageWeb/audio/...` และ `XStageWeb/lyrics/...` เป็นไฟล์เสียง M4A/เนื้อร้อง JSON

### ทำได้อัตโนมัติเมื่อซิงค์ R8 ไปยังบัญชีเดิม

1. **ถ้ามี `current.json` รุ่นเดิมอยู่แล้ว:** อ่านฐานเดิมและใช้ Drive File ID เดิม ตรวจไฟล์ที่เปลี่ยนจริงเท่านั้น
2. **ถ้ามีเฉพาะ `database.json` แบบเก่า:** นำแถวที่มี `webSongId`/`audio.fileId` และข้อมูลที่โปรแกรมรองรับเข้าฐานรุ่นใหม่ แล้วเผยแพร่ `current.json` ใหม่เมื่อผ่านการตรวจ ไม่อัปโหลด M4A ใหม่
3. **หากเคยอัปโหลด M4A + Lyrics แล้วแต่ไม่มีแถว DB:** ใช้ `Data/WebAssets` (ไฟล์ cache/proof เดิม) และตรวจลายเซ็นไฟล์กับ MD5 บน Drive เพื่อกู้ Drive File ID แล้วเพิ่มรายการเข้า Catalog โดยไม่ต้องแปลงและอัปโหลดซ้ำ
4. **ถ้าไฟล์ proof/cache เดิมหาย:** จะต้องใช้เพลงต้นฉบับและ SoundFont ตรวจ/สร้างไฟล์อีกครั้งเพื่อยืนยัน hash ก่อน จึงจะใช้ไฟล์บน Drive เดิมได้; อาจต้องอัปโหลดใหม่หากไฟล์ที่สร้างออกมาไม่ตรง MD5
5. หลังนำรายการเก่ากลับมาได้ครบตามที่ตรวจสอบ ระบบจะเผยแพร่ Snapshot/Delta ตามชุด ปล่อยให้เว็บใช้ฐานล่าสุดได้ **แม้ซิงค์ส่วนที่เหลือไม่เสร็จ**

### วิธีใช้

1. สำรอง `D:\newKaraoke\Data` และเก็บ `Data/WebAssets` เดิมไว้ **ห้ามล้าง Cache/Journals** ก่อนซิงค์ต่อ
2. แตก ZIP R8 ไปยังโฟลเดอร์ใหม่ ไม่ติดตั้งทับ EXE เดิมระหว่างซิงค์
3. ใช้ `Verify-Windows-0948.cmd` ตรวจ Build Gate แล้ว `Build-Windows.cmd`; ตัวหน้าซิงค์ต้องขึ้น `DB Recovery R8`
4. เปิดจาก Google Login หน้าแรกด้วย **บัญชี Google Drive เดิม** เลือก **ประเภทเพลง** และ **SoundFont เดิม** แล้วกด `ซิงค์ต่อจากครั้งก่อน`
5. ตรวจ Log: `ข้ามเพลงเดิม`, `กู้คืนเพลงที่อัปโหลดครบแล้ว`, `เผยแพร่ฐานเพลงรุ่น ...` และจำนวนเพลงที่เว็บเห็น จากนั้นเปิด `https://webbase-x.github.io/xstage/?v=0965`

### ข้อจำกัด / ความปลอดภัย

- ห้ามพยายามคัดลอกชื่อไฟล์ลง DB ด้วยมือหรือสมมติ Drive File ID; การจับคู่ชื่ออย่างเดียวไม่เพียงพอ
- หากเคยใช้ SoundFont/เวอร์ชันตัวแปลงอื่น ลายเซ็นอาจเปลี่ยน ทำให้จำเป็นต้องแปลงใหม่
- ห้ามซิงค์ไปยัง `XStageWeb` เดียวกันพร้อมกันจากสองเครื่อง
- ถ้ารุ่นเก่าใช้โครงสร้างชื่อไฟล์และ DB ที่ไม่ตรงรุ่นนี้ ต้องสำรองไว้และทำการย้ายแบบเฉพาะก่อน ยังไม่ควรลบข้อมูลเดิม
- ไฟล์ที่สร้างจากการกู้คืนข้อมูลยังอยู่ใน Google Drive ส่วนตัว; ไม่มีการอัปโหลดเพลงสาธารณะไป GitHub Pages
