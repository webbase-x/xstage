# X-Stage Karaoke Online — Compact Wizard R16

รุ่นต่อจาก Fast Sync / Verify & Repair R15

## การเปลี่ยนแปลง

- ทั้ง 3 หน้าต่างจัดวางแบบกึ่งกลาง ปรับตามความกว้างหน้าต่าง โดย **ไม่ใช้แถบเลื่อน**
- หน้าต่างเริ่มต้นกระชับขึ้น (สูงสุด 680 × 460 พิกเซลสำหรับพื้นที่ทำงานทั่วไป)
- หน้า 1: บัญชี Google และปุ่มเข้าสู่ระบบ/ถัดไป
- หน้า 2: โปรไฟล์ ชื่อ อีเมล SoundFont ประเภทเพลง จำนวนเพลง และปุ่มเริ่ม/ซิงค์ต่อ
- หน้า 3: โปรไฟล์ แถบแปลงเพลง อัปโหลด ฐานเว็บ Google Drive ใช้จริง/คาดการณ์ และปุ่มหยุด/สำเร็จ
- ตัดข้อความคำอธิบายยาว สถานะพื้นที่จะแสดงเปอร์เซ็นต์เมื่อมีข้อมูลโควตาและประมาณการที่ตรวจสอบได้จริง
- ย่อชื่อและอีเมลยาวให้พอดีโดยไม่เปลี่ยนข้อมูลบัญชีที่ใช้ยืนยันตัวตน
- พื้นที่มากกว่า 600 พิกเซลจะจำกัดความกว้างเนื้อหาและจัดกึ่งกลาง เพื่อไม่ให้ UI ยืดยาวผิดสัดส่วน

## ที่ไม่ได้เปลี่ยน

- OAuth Desktop, DPAPI, บัญชีที่จดจำไว้
- การซิงค์แบบ Pipeline, รายการเพลงบน Drive, ระบบตรวจและซ่อม MD5
- SQLite Journal และงานที่หยุดไว้ซึ่งทำต่อได้
- พฤติกรรมไม่ปิดหน้าต่างหรือเปิดเว็บไซต์อัตโนมัติเมื่อเสร็จ

## ผลทดสอบ

- GUI สามหน้า + ระบบเก็บงานค้าง + แถบ Google Drive: 21 รายการผ่าน (Linux/Xvfb)
- Regression ใหม่: ไม่มี Scrollbar และไม่พบ Widget ล้นขอบที่ 680×460, 480×380, 320×310 (พร้อมรูปโปรไฟล์ 44×44 และชื่อบัญชียาว): 2 รายการผ่าน
- หน่วยทดสอบ Online/Drive/Recovery สำคัญ: 49 รายการ (ผ่าน 38 ข้าม 11)
- ยังไม่ได้ Build EXE หรือทดสอบ Google Drive บน Windows จริง ต้องให้ Windows Build Gate ตรวจครบก่อนติดตั้ง

## ติดตั้ง/ทดสอบ

1. สำรอง `D:\newKaraoke\Data` ไม่ลบ `WebAssets` หรือไฟล์ OAuth จริง
2. แตก ZIP ในโฟลเดอร์ใหม่ (หรือแตก Hotfix R16 ลงบนซอร์ส R15)
3. รัน `Verify-Windows-0948.cmd` และ `Build-Windows.cmd` หลังตรวจผ่าน
4. เปิดจากเมนูคลิกขวา `X-Stage Karaoke Online` ทดสอบหน้าต่างทั้ง 3 หน้าและการกู้คืนงานเดิม

สำหรับหน้าจอความละเอียดต่ำมากและ Windows Scaling สูงผิดปกติ ตัวระบบปฏิบัติการอาจไม่เหลือพื้นที่เพียงพอให้ทุกตัวควบคุมแสดงได้พร้อมกัน; ควรทดลองที่ระดับการปรับขนาดหน้าจอที่ใช้งานจริงก่อนติดตั้งแทนโปรแกรมหลัก
