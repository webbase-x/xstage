# สร้างรายการเพลงและรายชื่อเพลง — รุ่น 0.5.79

เปิดจากคลิกขวา → จัดการข้อมูลเพลง

1. กด “แหล่งเพลง” เพื่อขยายส่วนเลือกโฟลเดอร์ เลือกประเภท แล้วกดเพิ่มโฟลเดอร์
2. กด “เริ่มสร้างรายการ” ค่าเริ่มต้นตรวจเฉพาะเพลงใหม่/ที่เปลี่ยน หากต้องการอ่านใหม่ทั้งหมด ให้ติ๊ก “อ่านรายละเอียดใหม่ทั้งคลัง” ก่อนเริ่ม
3. ดูเป้าหมาย จำนวนตรวจแล้ว รายการพร้อมใช้ ข้าม/อ่านไม่ได้ เพลงซ้ำ ความคืบหน้าร้อยละ และรายการที่ตรวจล่าสุดในหน้าต่างเดียว
4. แท็บ “รายชื่อเพลงในคลัง” ค้นหาชื่อ ศิลปิน หรือรหัส แล้วเลือกดูรายละเอียด แก้ข้อมูล หรือตั้งเพลงโปรดได้ โดยไม่เปลี่ยนรายการที่เลือกบนจอร้อง

ส่วนแหล่งเพลงพับอัตโนมัติเมื่อเริ่มงาน และเมื่อเปิดครั้งแรกที่มีโฟลเดอร์อยู่แล้ว กดชื่อส่วนเพื่อเปิดกลับได้ ปุ่มเริ่ม/ยกเลิก/ซ่อน/รายงานอยู่ด้านล่างตลอด การซ่อนหน้าต่างไม่หยุดงาน การยกเลิกยังเก็บรายการที่บันทึกสำเร็จแล้ว ไม่ลบไฟล์ต้นฉบับ

ตารางผลตรวจแสดงล่าสุด 300 รายการ; บันทึกผลตรวจฉบับเต็มเปิดจากปุ่มด้านล่าง ตารางคลังแบ่งหน้า 100 รายการ และแสดงผลค้นหาสูงสุด 5,000 รายการต่อคำค้น หากคลังใหญ่ให้ระบุคำค้นเพิ่ม ค้นหาผ่านการอ่านฐานข้อมูลเบื้องหลัง รายชื่อรีเฟรชเมื่อจบงานหรือกดรีเฟรช

หน้าต่างมีแถบเลื่อนเมื่อพื้นที่ไม่พอ จึงยังเข้าถึงส่วนที่เหลือได้บนจอเล็กหรือเมื่อขยายตัวอักษร Windows

การตรวจในรุ่นนี้: ทดสอบตรรกะอัตโนมัติและหน้าต่าง Tk บน Linux/Xvfb ยังไม่ใช่การรับรองการแสดงผลทุกระดับ DPI บน Windows หรือการทดสอบเสียงจริง
