# X-Stage Karaoke Online — Account & Sync Wizard R10

**พื้นฐานซอร์ส:** v0.9.48 / BuildGate + Legacy DB Recovery R8  
**ชนิด:** Windows source update (ไม่ใช่ EXE สำเร็จรูป)

## หน้าต่างใหม่

เปิดจาก **เมนูคลิกขวา → X-Stage Karaoke Online…** ภายในโปรแกรม PC เดิม

1. **Google Drive Login** — เป็นหน้าแรกของหน้าต่าง Online เท่านั้น ไม่มีแถบ Google Login ทับหน้าหลักของเครื่องเล่นอีกต่อไป ระบบจะพยายามคืนเซสชันที่เข้ารหัสด้วย Windows DPAPI *เมื่อเปิดเมนู Online* ไม่เชื่อมต่อ Google เองเมื่อเพิ่งเปิดโปรแกรม หากไม่มีบัญชีให้กด Login Google ผ่านเบราว์เซอร์ ผู้ใช้ต้องเป็นเจ้าของบัญชี
2. **ยืนยันบัญชีและตั้งค่าการซิงค์** — แสดงชื่อและอีเมลที่ยืนยันได้ รูปโปรไฟล์ (ถ้ามี) และตัวเลือก SoundFont / NCN / MIDI พร้อมจำนวนเพลงที่ตรวจพบ กด **ตกลง** เพื่อเริ่มงาน กรณีมีงานค้างจะแสดง **ตกลง • ซิงค์ต่อจากครั้งก่อน** โดยไม่มีการอัปโหลดอัตโนมัติ
3. **ความคืบหน้าแยกขั้นตอน** — แสดงแถบสีฟ้าสำหรับการแปลงเพลง สีเหลืองสำหรับอัปโหลด และสีเขียวสำหรับฐานเว็บ มีเปอร์เซ็นต์จากจำนวนเพลงที่ตรวจสอบได้จริง และแสดงเวลาที่ผ่านไปกับข้อความล่าสุดเมื่อยังไม่สามารถระบุเปอร์เซ็นต์ได้
4. **เมื่อซิงค์สำเร็จครบและไม่มีเพลงผิดพลาด** — ปิดหน้าต่าง Online แล้วเปิดหน้า `https://webbase-x.github.io/xstage/` ในเบราว์เซอร์ หากซิงค์ล้มเหลวหรือมีเพลงตกค้าง จะไม่อ้างว่าสำเร็จและไม่เปิดเว็บโดยอัตโนมัติ

หน้าต่างใช้พื้นที่เลื่อนแนวตั้ง เพื่อไม่ให้ตัวเลือกหรือสถานะถูกตัดบนจอเล็กหรือระบบที่ขยายตัวอักษรสูง และสามารถเปิดซ้ำได้โดยไม่สร้างงานซิงค์ซ้อน

## การหยุดและกลับมาทำต่อ

- กด **หยุด**: ตั้งสัญญาณยกเลิกและรอให้ไฟล์ที่กำลังเขียนจบอย่างปลอดภัย ไม่ลบฐานเพลงหรือไฟล์ที่อัปโหลดสำเร็จ
- กด **ปิด** ระหว่างทำงาน: ขอหยุดอย่างปลอดภัยก่อนปิด; หาก Google Drive ยังตอบช้าหรือ FFmpeg ยังทำงานอยู่ การปิดอาจใช้เวลา
- ปิดโปรแกรม / ไฟดับ: สถานะ Online ใน `Data/WebAssets/online-sync-recovery.json` กับ SQLite Journal ช่วยกู้คืน **รายการที่ตรวจสอบและอัปโหลดครบแล้ว** โดยตรวจไฟล์บน Google Drive อีกครั้งก่อนข้ามงาน
- ข้อมูลที่อัปโหลดครบและเผยแพร่ `current.json` แล้ว ยังเปิดเล่นได้ผ่านเว็บขณะซิงค์ต่อ; งานที่จบกลางไฟล์อาจต้องตรวจสอบ/เริ่มแปลงใหม่
- ไม่อัปโหลดงานค้างอัตโนมัติเมื่อเปิดใหม่: ต้องผ่าน Login / เลือกการตั้งค่า / **ตกลง** อีกครั้ง

## วิธีทดสอบและ Build บน Windows

1. สำรอง `D:\newKaraoke\Data` และเก็บ OAuth Desktop Client JSON ไว้ **นอกชุดซอร์ส/ไฟล์ ZIP**
2. แตก ZIP ซอร์ส R10 ลงโฟลเดอร์ใหม่ **ไม่แตก/Build ขณะยังอยู่ใน ZIP**
3. รัน `Verify-Windows-0948.cmd` ให้ผ่าน (มี Python 3.13 x64 และ dependency ตามเอกสารของโครงการ)
4. รัน `Build-Windows.cmd` เมื่อ Test Gate ผ่านเท่านั้น
5. ทดลอง EXE ที่สร้างใหม่กับคลังทดสอบก่อนใช้ฐานเพลงจริง; ตรวจหน้า Login → ยืนยัน → Progress → เปิดเว็บ และหยุด/เปิดใหม่
6. อย่าเปิดซิงค์ไปยัง Google Drive โฟลเดอร์เดียวกันพร้อมกันจาก Windows หลายเครื่อง

## สรุปการทดสอบในสภาพแวดล้อมนี้

- Python 3.13 / Linux/Xvfb: ค้นพบ 1,124 รายการ รันจริง 1,119 รายการ ผ่าน 1,054 ข้าม 65; Failures 0 Errors 0
- 5 รายการที่ไม่ได้รันต้องใช้ `powershell.exe` บน Windows
- GUI เฉพาะ Online ใหม่: ทดสอบเปิด/ปิด หน้า 1→2→3, กลับมาเปิดซ้ำ, ซิงค์ต่อจากงานค้าง, การตั้งค่า SoundFont, กดหยุด และการปิดพร้อมเปิดเว็บไซต์จำลอง
- ทดสอบรูปแบบหน้าต่างบนจอจำลอง 1280×800, 800×600 และ 640×480; หน้ายืนยันมี Scrollbar เมื่อเนื้อหาสูงกว่าหน้าต่าง
- **ยังไม่ได้สร้าง EXE หรือทดลอง Google OAuth/Drive จริงบน Windows** อย่าถือว่าผ่าน Build Gate ของเครื่องใช้งานจนกว่าจะรันบน Windows สำเร็จ

## ข้อจำกัดที่ควรทราบ

- ไม่สามารถรับประกันได้ว่าไม่มีข้อบกพร่องหรือข้อปรับปรุงเหลืออยู่โดยไม่มีการทดสอบบน Windows จริงกับเพลงและบัญชีของผู้ใช้
- บางการสื่อสารเครือข่ายของ Google และงาน FFmpeg ใช้เวลา; UI แสดงเวลาและเตือนเมื่อไม่มีความคืบหน้าใหม่ แต่การขอหยุดต้องรอให้คำสั่งที่กำลังทำงานสิ้นสุดก่อน
- ไม่มีการเปลี่ยนฐานเพลงต้นฉบับ/เพลงจริงด้วยสคริปต์ทดสอบในชุดนี้
