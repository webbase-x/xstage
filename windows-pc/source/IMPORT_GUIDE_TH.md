# นำเข้าเพลง — รุ่น 0.8.0

เปิดหน้ารายการเพลง → เพิ่มไฟล์ / กำหนดโฟลเดอร์แล้วเริ่มสร้างรายการ / นำเข้าคลังเดิม
ก่อนนำเข้ามีตัวเลือก “คัดลอกเข้า Songs/ประเภทไฟล์” ค่าเริ่มต้นไม่เลือก หมายถึงอ้างอิงต้นฉบับโดยไม่ย้ายไฟล์
หากเลือกคัดลอก เพลงใหม่จะอยู่ใน Songs/MIDI, Songs/Audio หรือ Songs/Video ภายใต้โฟลเดอร์ติดตั้ง รวมไฟล์เนื้อร้องที่เข้าชุด

ชื่อเพลงและนักร้องซ้ำกัน (ไม่สนตัวพิมพ์และช่องว่างส่วนเกิน) จะแสดง “ซ้ำ” ในรายการ และเลือก ID แรกไว้ เพลงที่นักร้องว่างยังไม่รวมเป็นกลุ่มชื่อตรงกัน
นำเข้าทีละไฟล์จะถามใช้เดิม / ใช้ไฟล์ใหม่แทน ID เดิม / เก็บทั้งสอง; ค่าเริ่มต้นใช้เดิม
นำเข้าหลายไฟล์จะข้ามเพลงใหม่ที่ซ้ำแล้วแจ้งเหตุผลกับ ID เดิมในรายงาน หากต้องการเลือกอีกเวอร์ชันให้นำเข้าไฟล์นั้นทีละเพลง
ไฟล์ที่เนื้อหาเพลงและเนื้อร้องประกอบเหมือนรายการเดิมจะใช้เดิม ไม่สร้างสำเนาใหม่ แม้ชื่อไฟล์ต่างกัน
ไฟล์ชื่อชนแต่เนื้อหาต่างกันใช้ชื่อเพิ่มเลข (2), (3) โดยไม่เขียนทับ

การสร้างรายการยังตรวจไฟล์เดิมแบบ incremental: ไฟล์ที่ไม่เปลี่ยนและ metadata ครบใช้ผลเดิม เพลงที่เปลี่ยน/ข้อมูลไม่ครบตรวจใหม่โดยรักษา ID และข้อมูลที่แก้เอง
ตัวเลือกคัดลอกใช้กับรายการใหม่ การสร้างรายการไม่ย้ายไฟล์ที่มี ID เดิมอยู่แล้ว
ชุด NCN ที่มี LYR หรือ CUR เพียงอย่างเดียวถูกข้ามพร้อมเหตุผล ต้องเติมให้ครบก่อนนำเข้า ไม่มีการลบต้นฉบับ

งานที่ยกเลิกเก็บรายการที่ทำเสร็จไว้ หากเกิดข้อผิดพลาดหลังคัดลอกอาจเหลือไฟล์ที่ยังไม่ลงฐานข้อมูล ให้นำเข้าใหม่เพื่อใช้ไฟล์ที่ตรวจแล้ว รายละเอียดดูรายงานในหน้ารายการเพลง
