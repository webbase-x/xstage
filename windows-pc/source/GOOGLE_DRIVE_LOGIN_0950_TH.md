# X-Stage Karaoke Online • เข้าสู่ระบบ Google Drive ในหน้าต่างซิงค์ (Hotfix ซอร์ส Windows 0.9.48)

## สิ่งที่ปรับปรุง

- เพิ่มแถว **Google Drive • บัญชีที่ใช้ซิงค์** ในหน้าต่าง **X-Stage Karaoke Online — แปลงและซิงค์** ตั้งแต่เริ่มเปิด
- ปุ่ม **เข้าสู่ระบบ Google** เปิดเบราว์เซอร์เพื่อยืนยันบัญชีครั้งแรก ก่อนเลือกซิงค์ได้
- ปุ่ม **เลือก OAuth JSON เดิม…** ใช้ `google-oauth-client.json` หรือ `client_secret_*.apps.googleusercontent.com.json` จาก X-Stage รุ่นเก่า (ต้องเป็นชนิด **Desktop App** ไม่ใช่ Web OAuth Client)
- หากไฟล์อยู่ที่ `D:\newKaraoke\Data` โปรแกรมค้นหาให้ก่อนตามเส้นทางที่รู้จัก หากอยู่ที่อื่นให้กดเลือกไฟล์ ระบบคัดลอก JSON ที่เลือกไป `Data/google-oauth-client.json` โดยไม่แก้ไขไฟล์ต้นฉบับ
- หลังยืนยัน Google ครั้งแรก โปรแกรมเก็บ **Refresh Token ด้วย Windows DPAPI** ผูกกับบัญชีผู้ใช้ Windows ไว้ที่ `Data/xstage-google-session.dpapi` ไม่บันทึก Access Token, รหัสผ่าน Google หรือไฟล์เพลงลงในไฟล์ดังกล่าว
- เปิดหน้าต่างซิงค์ครั้งถัดไปจะลองคืนเซสชันอัตโนมัติ สามารถกด **ยกเลิกการจดจำบัญชี** เพื่อลบไฟล์ DPAPI ได้ทันที
- ระหว่างอัปโหลดต่อเนื่อง `Drive` ยังต่ออายุ Access Token ผ่าน Refresh Token ที่ Google ออกให้ตามสิทธิ์ที่ได้รับ
- แก้ไขคำแจ้ง OAuth JSON ไม่พบจากรุ่นเก่าให้เลือกไฟล์ได้ตั้งแต่ขั้นตอนแรก ไม่ต้องรอจนกดซิงค์

## ขั้นตอนทดลองใช้งาน

1. **สำรองโปรแกรมเดิมและข้อมูลใน `D:\newKaraoke\Data`** ก่อน และแตกไฟล์ ZIP ซอร์สชุดใหม่นี้ลงโฟลเดอร์ใหม่ อย่าคัดลอกทับโปรแกรมที่ใช้งานจริงทันที
2. เปิด `Verify-Windows-0948.cmd` เพื่อทดสอบ; Build ด้วย `Build-Windows.cmd` เฉพาะเมื่อ Test Gate ผ่านทั้งหมด
3. เข้าเมนูซิงค์ X-Stage Online: แถว Google Drive จะแสดงบัญชีที่จดจำ หรือปุ่มเลือก JSON / เข้าสู่ระบบ
4. หากขึ้นว่าไม่พบ Desktop OAuth Client: กด `เลือก OAuth JSON เดิม…` และเลือกไฟล์จาก `Data` ของโปรแกรมรุ่นก่อน จากนั้นกด `เข้าสู่ระบบ Google`
5. ยืนยันในเบราว์เซอร์ และกลับหน้าต่างซิงค์ที่จะแสดงอีเมลบัญชี Google
6. คลิกซิงค์เมื่อตรวจฐานเพลงครบ; ปิดแล้วเปิดใหม่ควรขึ้นชื่อบัญชีเดิมอัตโนมัติโดยไม่ต้องล็อกอินซ้ำ **ตราบใดที่ Google ยังอนุญาต Refresh Token**

## ข้อจำกัดและความปลอดภัย

- **จำบัญชีได้ถาวรใน Windows เท่าที่ Refresh Token ยังใช้งานได้เท่านั้น** หาก Google เพิกถอนสิทธิ์, เปลี่ยนรหัสผ่านบางกรณี, โครงการ OAuth อยู่สถานะ Testing หรือไม่ได้ใช้งานนาน อาจต้องลงชื่อเข้าใช้อีกครั้ง; ไม่สามารถข้ามข้อกำหนดของ Google ได้
- ไฟล์ `.dpapi` ถอดรหัสได้เฉพาะ Windows User เดิมบนเครื่องที่บันทึกไว้; ย้ายไฟล์ไป PC อื่นไม่สามารถนำไปล็อกอินได้
- ไม่ใส่ Google OAuth client JSON จริงหรือโทเค็นใน ZIP, GitHub หรือฐานข้อมูลเพลง; โฟลเดอร์ `Data` ไม่ถูกรวมในชุด source
- บัญชีที่ลงชื่อเข้าใช้ฝั่ง Windows จะซิงค์ขึ้น Drive ของบัญชีนั้นเท่านั้น ส่วนผู้ใช้มือถือ **ไม่ต้องลงชื่อเข้าใช้ Google** เพื่อใช้หน้าเว็บขอเพลงจาก QR
- ทดสอบระบบ DPAPI/Google OAuth จริงบน Windows 11 หลัง Build เท่านั้น ชุด Unit Test ข้ามขั้นตอนเครือข่าย Google และใช้ Mock เพื่อทดสอบตรรกะ
