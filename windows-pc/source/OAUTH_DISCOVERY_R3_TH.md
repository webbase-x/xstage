# X-Stage Karaoke Online — Google OAuth Discovery R3 (Windows Source v0.9.48)

## ความหมายของภาพ Recovery r2

- Google Login ปรากฏบนหน้าต่างแรกแล้ว แต่ยัง **ไม่สามารถเชื่อมบัญชี** หากขึ้นว่า "ไม่พบ Google OAuth Desktop Client".
- "6,500 / 147,787" คือแถวฐานข้อมูลที่ระบบกำลังตรวจสอบ **ไม่ใช่จำนวนเพลงที่พร้อมซิงค์**; รอให้ขั้นตอนตรวจฐานเสร็จก่อนตรวจจำนวน NCN/MIDI ที่พร้อมใช้.
- ต้องมี Google OAuth Client JSON ชนิด **Desktop app** จากโปรเจ็กต์เดิมของเจ้าของบัญชี ไม่ใช่ Web Client JSON ของ GitHub Pages.

## แก้ไขทันทีโดยไม่ต้อง Build ใหม่

1. ขณะโปรแกรมกำลังสแกนฐานเพลง สามารถกด **เลือก OAuth JSON เดิม…** แล้วเลือกไฟล์ `google-oauth-client.json` หรือ `client_secret_*.json` จากโปรแกรม X-Stage รุ่นเก่าที่มีอยู่ได้เลย (หากปุ่มถูกปิดชั่วคราว ให้รอการตรวจฐานเสร็จ).
2. หากไม่รู้ว่าเก็บที่ไหน ให้เริ่มดู `D:\newKaraoke\Data`, `D:\newKaraoke`, โฟลเดอร์โปรแกรมรุ่นเก่า, หรือ AppData ของ X-Stage. ไม่ควรส่งไฟล์ JSON นี้ในแชทหรืออัปโหลดขึ้น GitHub.
3. กด **G เข้าสู่ระบบ Google Drive** และยืนยันในเบราว์เซอร์.
4. เมื่อสำเร็จจะมีชื่อบัญชีที่เชื่อม และหาก Google ออก Refresh Token ระบบบันทึกแบบเข้ารหัส Windows DPAPI เพื่อเชื่อมต่อในครั้งถัดไป.

## สิ่งที่แก้ใน R3

- เพิ่มค้นหาไฟล์ `google-oauth-client.json`, `oauth-client.json`, `client_secret_*.json` จาก Data/โปรแกรมเก่า, โฟลเดอร์ติดตั้งที่รู้จัก และ AppData เฉพาะชื่อโฟลเดอร์ X-Stage ตามความเหมาะสม; **ไม่ไล่ค้นทั้งไดรฟ์**.
- รองรับตัวแปรแวดล้อม `XSTAGE_GOOGLE_OAUTH_JSON` สำหรับผู้ใช้ที่ตั้งเส้นทางไฟล์ JSON เอง.
- เปิดหน้าต่างซิงค์แล้วระบุชื่อไฟล์ที่ค้นพบ หรือแจ้งชัดเจนว่ายังต้องเลือกไฟล์เอง; ตรวจไม่ให้ Web OAuth Client ปลอมเป็น Desktop Client.
- ปุ่มเลือกไฟล์เริ่มจาก Data ของโปรแกรมหรือโฟลเดอร์ที่พบ OAuth JSON ลดการหาไฟล์ใหม่ซ้ำ.
- ปรับตัวนับขั้นตอนที่ 1 จากคำว่า "เพลง" เป็น "แถวฐานเพลง" เพื่อแยกจากจำนวนเพลงพร้อมซิงค์.
- ไม่รวม Google Client JSON จริง, Token, ไฟล์เพลง หรือฐานข้อมูลส่วนตัวในชุดซอร์ส.

## วิธีใช้ซอร์สรุ่นใหม่

สำรอง `D:\newKaraoke\Data` → แตก ZIP ลงโฟลเดอร์ใหม่ → รัน `Verify-Windows-0948.cmd` ให้ผ่านทั้งหมด → `Build-Windows.cmd` → ทดสอบ EXE ใหม่ก่อนติดตั้งทับ.

ชุดนี้เป็น **ซอร์ส ไม่ใช่ EXE** ที่ติดตั้งให้อัตโนมัติและยังไม่ได้ทดสอบ Google Sign-In จริงบน Windows ของผู้ใช้; ห้ามอ้างว่า Google เชื่อมต่อแล้วจนกว่าโปรแกรมจะแสดงบัญชีของผู้ใช้สำเร็จ.
