# ระบบเสียงเพิ่มเติม — 0.5.44 Source Preview

## WAV/MP3: ปรับคีย์แยกจากความเร็ว

1. หลังติดตั้ง เปิด `Setup-Audio.cmd` ในโฟลเดอร์ติดตั้ง เพื่อดาวน์โหลด BASS, BASSMIDI และ BASS FX x64 จากผู้พัฒนาโดยตรง ต้องใช้อินเทอร์เน็ตในขั้นตอนนี้
2. หากใช้ซอร์ส ให้รัน `powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Audio.ps1` จากโฟลเดอร์ซอร์ส
3. เปิดเพลง WAV/MP3 ใหม่ โปรแกรมจะเลือก BASS FX เมื่อพบ DLL ทั้งสองตัว ใช้การปรับคีย์/ความเร็วเดิม รวมทั้งคีย์แยกแต่ละรายการในคิวและคำขอจากมือถือ
4. เมื่อไม่มี DLL จะใช้เครื่องเล่นเดิม โดยไม่เปิดให้ปรับคีย์ WAV/MP3 การปรับความเร็ว WAV ด้วยเครื่องเล่นเดิมอาจเปลี่ยนระดับเสียงตามไปด้วย

ไฟล์วิดีโอ/WMA ยังใช้ codec ของ Windows และยังไม่รองรับการปรับคีย์แยกจากความเร็วในรุ่นนี้

## เครื่องมือ → ปรับเสียง EQ

ปรับทุ้ม กลาง แหลม ได้ -12 ถึง +12 dB กดใช้ค่าเพื่อใช้กับเพลงปัจจุบันและบันทึกเป็นค่าเริ่มต้น
ใช้ได้กับ SoundFont ผ่าน BASS และ WAV/MP3 ผ่าน BASS FX เท่านั้น ไม่ปรับเสียง MIDI ภายนอกหรือเครื่องเล่นวิดีโอ MCI
คืนค่าเดิมจะตั้งทุกย่านเป็น 0 dB การเร่ง EQ อาจทำให้เสียงแตก ควรลด gain ต้นทางด้วย
ความถี่ย่านแหลมปรับลงอัตโนมัติให้เหมาะกับ sample rate ของไฟล์

## เครื่องมือ → บันทึกเสียง

- อุปกรณ์รับเสียงเดียว: ใช้ไมค์หรือ Stereo Mix ที่เลือก เป็น WAV mono 48 kHz 16-bit ตามระบบ waveIn เดิม
- ไมค์ + เสียงลำโพง Windows: เลือกไมค์และสัดส่วนไมค์/ดนตรี บันทึกเป็น WAV stereo 48 kHz 16-bit
- โหมดผสมรับเสียง **ทุกโปรแกรมที่ส่งไปลำโพงเริ่มต้น** ไม่ใช่เฉพาะ X-Stage ปิดเสียงแจ้งเตือน/โปรแกรมอื่นก่อนบันทึก
- หากเปิด Listen to this device หรือมีการมอนิเตอร์ไมค์เข้า Windows อยู่แล้ว อาจเกิดเสียงไมค์ซ้ำ ให้ปิดหรือเลือกบันทึกจาก input เดียวของมิกเซอร์แทน
- แสดงเวลา ระดับเสียง และจำนวนตัวอย่างที่เกินระดับ พร้อมไฟล์ `.recording.json` หลังจบ
- บัฟเฟอร์มีขอบเขต หากอุปกรณ์หลุด รับเสียงไม่ทัน หรือสองอุปกรณ์เดินเวลาไม่ตรงกันจนบัฟเฟอร์เต็ม จะหยุดพร้อมแจ้งข้อผิดพลาด ไม่แสดงว่าสำเร็จ
- ไฟล์ WAV จำกัดประมาณ 4 GB (stereo 48 kHz 16-bit ประมาณ 6 ชั่วโมง) ระบบหยุดก่อนเกินขอบเขตและแจ้งให้เริ่มไฟล์ใหม่
- การเริ่มรับเสียงสองอุปกรณ์ไม่ใช่การล็อก clock ระดับฮาร์ดแวร์ ยังไม่มีการชดเชยความหน่วงอัตโนมัติ ต้องฟังไฟล์จริงเพื่อประเมินเสียงร้องตรงดนตรีกับอุปกรณ์ที่ใช้

## เครื่องมือ → ตรวจระบบเสียง

แสดงระบบปฏิบัติการ SoundCard และความถูกต้องของโครงสร้าง DLL x64 ก่อนทดลองใช้งาน
หยุด/ยกเลิกเพลงและจบบันทึกก่อนกด “ทดสอบลำโพง” ระบบจะเล่นเสียง 880 Hz ระดับเบาสั้น ๆ และอ่านเสียง loopback ของ Windows เป็นเวลา 3 วินาที
รายงานว่าตรวจพบเสียงทดสอบหรือไม่ ระดับสูงสุด ตัวอย่างเกินระดับ และข้อมูลผิดปกติ ส่งออกรายงาน JSON ได้
การทดสอบนี้ตรวจ **สัญญาณดิจิทัลที่ Windows ส่งออก** ไม่ยืนยันว่าลำโพงภายนอกมีเสียงจริง ไม่ใช่ค่าหน่วงจากลำโพงถึงหู และไม่ใช่การรับรองว่าเล่นหลายชั่วโมงไม่กระตุก
การวัดประสิทธิภาพ SoundFont ในแท็บทดสอบเดิมเป็นการสังเคราะห์ PCM แยกจากการตรวจ output นี้

## สถานะการตรวจรุ่นนี้

ทดสอบ logic ด้วย native bindings จำลอง สัญญาณเสียงจำลอง ไฟล์ WAV ที่สร้างจริง และ callback หน้าต่างจำลองบน Linux แล้ว
ยังไม่ได้รัน BASS FX, WASAPI, waveIn หรือหน้าต่าง Tk ของรุ่นนี้บน Windows จริง และยังไม่ได้สร้าง EXE ในสภาพแวดล้อมนี้
ดู WINDOWS_CHECK_TH.md สำหรับรายการทดสอบเครื่องจริงก่อนใช้งานหน้าเวที

## ฟังก์ชันที่ยังไม่รองรับ

ASIO, VST, audio bus, medley/fill แบบตรงห้องเพลง, electone, DMX USB, ตู้หยอดเหรียญ และตัวถอดรหัส XMK/XAK/XVK/XSF/EMK revision ที่ยังไม่มีข้อมูลรูปแบบและตัวอย่างทดสอบ
สิ่งเหล่านี้ไม่ได้เปิดเป็นปุ่มหลอกหรือรายงานว่าทำสำเร็จ ยังต้องพัฒนาและทดสอบเพิ่มเติมตามไดรเวอร์/ข้อกำหนดของระบบนั้น
