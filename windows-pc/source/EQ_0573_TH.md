# EQ ประจำเพลงและปรับเสียงสด — 0.5.73

ลากสไลเดอร์แล้วเสียงจะเปลี่ยนระหว่างลาก ไม่ต้องรอปล่อยเมาส์
รวมเหตุการณ์ที่เข้าถี่มากเป็นช่วงประมาณ 20 ms เพื่อลดภาระ UI ไม่มีการเขียน settings ลงดิสก์ทุกเฟรม
ลูกล้อปรับช่องที่เลือกทีละ 0.5 dB เช่นเดิม
การเปลี่ยนพรีเซ็ตยังใช้การไล่ค่าสั้น ๆ; ระบบบัฟเฟอร์/อุปกรณ์จริงยังมีความหน่วงตามการตั้งค่า

## จำ EQ เพลงนี้
1. เล่นเพลงผ่าน BASS แล้วปรับ EQ ตามต้องการ
2. กด “จำ EQ เพลงนี้” เพื่อเก็บค่าที่ใช้อยู่ รวม INPUT/OUTPUT/BYPASS และทั้ง 31 ช่อง
3. เปิดเพลงไฟล์เดิมอีกครั้ง โปรแกรมเรียกค่าก่อนเริ่มเล่นโดยอัตโนมัติ
4. กด “ลบค่าที่จำ” เพื่อลบเฉพาะเพลงนี้และกลับไปใช้ EQ กลาง

แยกตามพาธไฟล์เต็ม ไม่ใช้ชื่อเพลงหรือเลขรายการฐานข้อมูล จึงไม่สับสนเพลงชื่อซ้ำ
เปลี่ยนชื่อ/ย้ายตำแหน่งไฟล์ ต้องบันทึกค่าเพลงที่ตำแหน่งใหม่อีกครั้ง
ค่าอยู่ใน settings จึงเรียกคืนได้หลังปิดเปิดโปรแกรม
การปรับขณะเล่นเป็นค่าชั่วคราวจนกดจำเพลง; ไม่ทับค่า EQ กลางและไม่ทับเพลงก่อนหน้าที่กำลัง fade out
เมื่อไม่มีเพลงเล่น การปรับ EQ จะบันทึกเป็นค่ากลางสำหรับเพลงที่ไม่มีค่าประจำเพลง
หากเปลี่ยนเพลงระหว่างลาก/ไล่พรีเซ็ต จะยกเลิกงานปรับเก่าเพื่อไม่ให้กระทบเพลงใหม่
รองรับเพลงที่ผ่าน BASS เท่านั้น ไม่รวม MIDI ออกภายนอกหรือวิดีโอที่ใช้ระบบอื่น
