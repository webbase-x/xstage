# X-Stage Karaoke Windows — Account Home / Audit R6

**ฐานซอร์ส:** v0.9.48 No-Console Recovery R5 — ยังคง repository และโครงสร้างฐานเพลงเดิม
**รุ่นแก้ไข:** Account Home / Recovery r6 (ยังไม่ได้ Build EXE บน Windows)

## ความเปลี่ยนแปลง

1. **หน้าแรก Google Login แยกจากหน้าซิงค์**: เปิดโปรแกรมแล้วเข้าสู่หน้า X-STAGE KARAOKE / WELCOME ซึ่งสามารถเลือกเข้าสู่ระบบ Google Drive หรือเข้าเวทีแบบออฟไลน์ได้ บัญชีที่เคยอนุญาตจะคืนสิทธิ์อัตโนมัติหาก Refresh Token ยังใช้ได้
2. **แถบผู้ใช้ด้านบนจอหลัก**: แสดงชื่อ (เมื่อ Google userinfo ให้ข้อมูลที่ยืนยันได้), อีเมล และรูปภาพโปรไฟล์ (ถ้าดึงได้จากโดเมนภาพ Google ที่อนุญาต) พร้อมทางเข้าหน้าแรก/บัญชี; หากไม่มีภาพ ใช้อักษร G
3. **ถอดปุ่มตั้งค่า OAuth JSON ด้วยตนเองออกจากหน้าซิงค์**: โปรแกรมค้นหา Google Desktop OAuth JSON เดิมจาก Data/โฟลเดอร์ติดตั้งตามกลไกเดิม; ไม่มีไฟล์ OAuth จริงหรือโทเค็นบรรจุในซอร์ส
4. **หน้าซิงค์ใช้บัญชีเดียวกับหน้าแรก**: แสดงชื่อและอีเมลที่เชื่อมต่อแล้ว พร้อมปุ่มกลับไปจัดการบัญชีในหน้าแรก; ไม่เปิดหน้าต่าง OAuth หรือเลือก JSON อีกครั้งโดยอัตโนมัติ; ยังไม่อนุญาตให้ซิงค์หากยังไม่ได้ล็อกอิน
5. **ความปลอดภัย**: เก็บ Refresh Token เดิมใน Windows DPAPI ผูกกับบัญชี Windows; Access Token อยู่ในหน่วยความจำ; โหลดภาพโปรไฟล์เข้าหน่วยความจำโดยจำกัดโดเมนและขนาดภาพ ไม่บันทึกบนดิสก์; การเปลี่ยนบัญชีที่ไม่มี Refresh Token ใหม่ไม่เก็บเซสชันของบัญชีเก่าโดยผิดพลาด
6. **ความเสถียร GUI**: ยกเลิก Tk timer ของหน้า Account Home เมื่อปิดโปรแกรม ป้องกัน callback หลังทำลายหน้าต่าง; ขนาดรูปโปรไฟล์กลับสู่ค่าเดิมเมื่อออกจากระบบ
7. **ความสามารถเดิมคงไว้**: ระบบเพลง SQLite, queue.json, ซิงค์ต่อจากงานค้าง SQLite journal, FFmpeg แบบซ่อน CMD, MIDI/NCN, เมดเลย์, คิวเพลง, รีโมท และการ Build เดิม

## วิธีติดตั้งและทดลอง

1. **สำรอง** `D:\newKaraoke\Data` หรือโฟลเดอร์ข้อมูลปัจจุบันทั้งหมดก่อนทำการเปลี่ยนแปลง
2. แตก ZIP R6 ไปยังโฟลเดอร์ใหม่ **อย่าติดตั้งทับทันที**
3. ตรวจสอบไฟล์ Desktop OAuth ที่ใช้งานจริงให้อยู่ใน `D:\newKaraoke\Data\google-oauth-client.json` หรือโฟลเดอร์ที่ตัวค้นหาเดิมรู้จัก; ไม่จำเป็นต้องส่งไฟล์ดังกล่าวมาในแชท
4. รัน `Verify-Windows-0948.cmd` และ `Build-Windows.cmd` ตามลำดับ **บน Windows x64** เมื่อ Build Gate ผ่านจริงเท่านั้นจึงนำ EXE ใหม่มาทดลอง
5. เปิด EXE ใหม่ด้วยทางลัด `X-Stage Karaoke.lnk` หรือ `Start-XStage-Silent.vbs` แทนไฟล์ `.cmd` สำหรับการใช้งานทั่วไป
6. เมื่อเปิดโปรแกรมให้ตรวจหน้า WELCOME / Google Drive; หากมีเซสชันเดิมที่ยังใช้ได้ ระบบจะเชื่อมต่ออัตโนมัติและเข้าเวที หากไม่มีให้กดปุ่ม Google Login หรือเลือกเข้าเวทีแบบออฟไลน์
7. ตรวจแถบบนว่าปรากฏชื่อ/อีเมลและรูปโปรไฟล์ (รูปภาพเป็นทางเลือก); เปิดเมนูซิงค์ออนไลน์ตรวจชื่อหน้าต่าง **`[Recovery r6]`** และข้อความสถานะบัญชี โดยไม่มีปุ่มเลือก OAuth JSON
8. ทดสอบเพลง NCN/MIDI, SoundFont, คิวเพลง, จอร้อง F11, รีโมท, ซิงค์ต่อหลังหยุด และปิดโปรแกรม/เปิดใหม่ก่อนใช้งานจริง

### ประเด็นที่ควรตรวจต่อบน Windows (เรียงตามความสำคัญ)

- **สูง** — ทดสอบ Build Gate, การเปิดตัวเล่นหลังติดตั้ง, ภาพเนื้อร้องกับ GDI/Uniscribe, ระบบเสียงและ FFmpeg ว่าไม่มี CMD เด้ง
- **สูง** — ทดสอบ Google OAuth Desktop จริงกับสิทธิ์ Drive, ความหมดอายุ Refresh Token และการสลับบัญชี ขณะไม่มีงานซิงค์
- **สูง** — ทดสอบ Google Drive Resume กับโฟลเดอร์เพลงจำนวนมากและการหยุดงานระหว่างอัปโหลด โดยตรวจ Checksum บน Drive ก่อนข้ามรายการ
- **กลาง** — ทดสอบแถบชื่อ/รูปโปรไฟล์ที่ความละเอียด 1366×768, 1920×1080, จอ DPI 125–200% และหลายจอ
- **กลาง** — ตรวจการใช้งานออฟไลน์ เมื่อไม่มี OAuth JSON หรือเน็ตขาด และการคืนบัญชีเมื่ออินเทอร์เน็ตกลับมา
- **กลาง** — ตรวจสิทธิ์ไฟล์ Data และการสำรองเพลง/คิว ก่อนการอัปเกรดจริง

**ข้อจำกัด:** นี่คือชุดซอร์ส ไม่ใช่ EXE ที่ติดตั้งแล้ว และไม่เปลี่ยนโปรแกรมใน `D:\newKaraoke` โดยอัตโนมัติ การเปิดเพลงและล็อกอินจริงยังต้องทดสอบบน Windows หลัง Build สำเร็จ
