# X-Stage Karaoke Online — Streaming Sync Pipeline R7

## เป้าหมาย

ปรับซิงค์ NCN และ MIDI/KAR ไปยัง Google Drive **ส่วนตัวของเจ้าของบัญชี** โดยแปลงเสียงและอัปโหลดไฟล์ทำงานเหลื่อมกันเป็น Pipeline ไม่ต้องรอให้แปลงเพลงทุกเพลงก่อนจึงเริ่มอัปโหลดหรือเปิดเว็บ

- แปลงด้วยตัวทำเสียง/FFmpeg เดิม แล้วสร้าง M4A และ Lyrics JSON
- เริ่มแปลงเพลงถัดไปด้วยตัวทำงานเบื้องหลังขณะตรวจและอัปโหลดเพลงก่อนหน้า (จำนวนงานรอจำกัดตามจำนวน Workers)
- หลัง **10 เพลงใหม่ที่อัปโหลด M4A และ Lyrics JSON ครบและผ่านการตรวจสอบ** จะเผยแพร่ Catalog ชุดแรก (`database-<generation>.json` + `current.json`)
- ชุดต่อไปเผยแพร่เมื่อมีการเปลี่ยนแปลง 200 เพลง หรือผ่านไป 180 วินาที (ตรวจเมื่อจบการประมวลผลแต่ละเพลง) โดยส่งเฉพาะ Delta Catalog และอัปเดต `current.json` หลังตรวจการอัปโหลดสำเร็จ
- หากมีเพลงน้อยกว่า 10 เพลง จะเผยแพร่ Catalog เมื่อจบงานโดยไม่รอจนถึง 10 เพลง
- ทุก ๆ 20 Delta จะรวมเป็น Snapshot ใหม่เพื่อลดจำนวนไฟล์ที่เว็บไซต์ต้องอ่าน; เมื่อจบงานจะรวมฐานฉบับสมบูรณ์อีกครั้ง
- เว็บไซต์ `https://webbase-x.github.io/xstage/` รุ่น 0965 อ่าน Catalog หลักและ Delta จาก Drive ส่วนตัว ตรวจการอัปเดต `current.json` ทุก 45 วินาที และเพิ่มเพลงค้นหาได้โดยไม่หยุดเพลงที่กำลังเล่น

## ตัวอย่างการทำงาน

1. แปลงเพลง 1–10 / อัปโหลดและตรวจ M4A+Lyrics ของเพลงแต่ละรายการ ขณะที่ Worker แปลงเพลงถัดไป
2. เผยแพร่ฐานเพลงชุดแรก 10 เพลง → เว็บไซต์ลงชื่อเข้าใช้ Google แล้วค้นหา/เล่น 10 เพลงนี้ได้ทันที
3. แปลงและอัปโหลดชุดที่ 2 ต่อไป โดยเผยแพร่ Delta จากไฟล์ที่ตรวจแล้วเป็นระยะ
4. เว็บไซต์ที่เปิดอยู่ตรวจฐานชุดใหม่และแสดงเพลงเพิ่มโดยอัตโนมัติ (ประมาณทุก 45 วินาที ขึ้นกับเครือข่าย)
5. เมื่อเสร็จทั้งหมด เขียน Catalog ฉบับรวมที่ปลอดภัย แล้วให้ `current.json` ชี้ไปยัง Snapshot ใหม่

## หยุด ปิด ยกเลิก และซิงค์ต่อ

- สามารถกด **หยุด** ที่หน้าต่างซิงค์ หรือปิดโปรแกรมตามขั้นตอนปกติ แล้วเปิดใหม่เลือก **ซิงค์ต่อจากครั้งก่อน**
- SQLite Journal ใน `Data/WebAssets` บันทึกเฉพาะเพลงที่อัปโหลด **ครบทั้ง M4A/JSON** และตรวจ Metadata/Checksum สำเร็จแล้ว
- โปรแกรมเปิดงานใหม่โดยตรวจ Drive และไฟล์ต้นฉบับอีกครั้งก่อนข้ามรายการเดิม ไม่เชื่อเพียงตัวเลขที่เคยทำไป
- หากไฟดับกลางเพลง ชุดล่าสุดที่ `current.json` ชี้อยู่จะยังเปิดเล่นได้; ไฟล์ที่อัปโหลดครึ่งเดียว **ไม่ถูกเผยแพร่**
- หากค้างหลังอัปโหลด แต่ก่อนอัปเดตฐาน เพลงที่ยืนยันครบแล้วจะถูกตรวจและนำกลับมาใช้ในการซิงค์ครั้งหน้า
- ไม่ลบเพลงหรือ Catalog เก่าบน Drive อัตโนมัติ และไม่ส่งไฟล์ `songs.sqlite3`, `queue.json` หรือ Token ไปที่ GitHub

## โครงสร้างฐานใหม่ (รองรับของเก่า)

- `current.json`: `schemaVersion:1`, `generation`, `catalogFileId`, `songCount`, และ `deltaFileIds` (ถ้ามี)
- Snapshot `database-*.json`: `schemaVersion:1`, `songs:[]` เหมือนเดิม
- Delta `delta-*.json`: `schemaVersion:1`, `upserts:[]`, `removes:[]` โดยไม่มีเพลงที่ไม่ผ่านการตรวจสอบ
- รุ่นเว็บเก่าที่อ่านเพียง `catalogFileId` จะเห็นเฉพาะ Snapshot หลัก **ไม่เห็น Delta**; ต้องใช้เว็บรุ่น 0965 ขึ้นไปเพื่ออัปเดตเพลงระหว่างซิงค์
- ห้ามซิงค์ไปยังโฟลเดอร์ XStageWeb เดียวกันจาก Windows หลายเครื่องพร้อมกัน เพราะ Google Drive `files.update` ไม่ใช่คำสั่ง Compare-and-Swap แบบธุรกรรมเต็มรูปแบบ

## ติดตั้ง / ทดสอบ

1. สำรอง `D:\newKaraoke\Data` โดยเฉพาะฐานเพลง คิว และ `Data/WebAssets` ก่อนทำสิ่งอื่น
2. แตก ZIP ซอร์ส R7 ลงโฟลเดอร์ใหม่ **ไม่ติดตั้งทับ EXE ที่กำลังซิงค์อยู่**
3. ใช้ `Verify-Windows-0948.cmd` ตรวจ Test Gate แล้ว `Build-Windows.cmd` ตามขั้นตอนเดิม
4. เปิดโปรแกรมใหม่ ตรวจชื่อหน้าต่างซิงค์ `[Pipeline r7]` และบัญชี Google จากหน้าแรก
5. เปิดเว็บด้วย `https://webbase-x.github.io/xstage/?v=0965` หลังฐานชุดแรกเผยแพร่ ดูจำนวนเพลงที่เพิ่มในเว็บ ขณะ Windows ยังซิงค์เพลงถัดไป
6. ทดลองกดหยุดหลังฐานชุดหนึ่งเผยแพร่ แล้วปิด/เปิดโปรแกรมใหม่และกดซิงค์ต่อ โดยตรวจว่าเพลงชุดที่เผยแพร่แล้วเล่นได้ และไฟล์เดิมไม่ถูกแปลงซ้ำอย่างไม่จำเป็น

## ผลทดสอบ / ข้อจำกัด

- ทดสอบด้วย Fake Drive และ Stub Renderer เท่านั้น ไม่ใช่การอัปโหลดเพลงจริงหรือบัญชี Google จริง
- ทดสอบ: การแปลงเพลงถัดไปขณะอัปโหลดเพลงแรก, เผยแพร่หลังชุดแรก, Delta ในชุดต่อไป, หยุด/ซิงค์ต่อ, ตรวจไฟล์เดิม, ล้มเหลวระหว่าง Delta, และล้มเหลวในขั้นรวม Catalog
- ยังคงข้อจำกัดเดิม: MP3/MP4 ไม่รองรับการแปลงผ่านตัวทำเสียง MIDI; ไม่มีการอ่าน BPM หรือดึง Token ไปไว้ในเว็บไซต์สาธารณะ
- ควรทดลอง Windows Build Gate, FFmpeg จริง, Google OAuth จริง, และคลังเพลงขนาดใหญ่ก่อนใช้งานแทนระบบหลัก
- การเล่นเพลงใหม่บนเว็บต้องมี M4A และ Lyrics JSON ครบ ต้องเข้า Google ด้วยบัญชีเจ้าของ Drive และต้องมีอินเทอร์เน็ต
