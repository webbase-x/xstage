# X-Stage Karaoke 0.5.75 — การควบคุม EQ ระหว่างแสดง

1. หมุนลูกล้อ/กดลูกศรเพิ่มลดแบนด์ และปุ่มเพิ่มลด Input มีผลกับเสียงทันที แต่รวมการบันทึกการตั้งค่าหลังหยุดปรับ 350 ms เพื่อลดการเขียนดิสก์ ค่ากลางถูกเก็บในหน่วยความจำทันทีและบันทึกเมื่อย่อ/ปิดตามปกติ การปิดแบบบังคับก่อนบันทึกอาจสูญเสียการเปลี่ยนแปลงล่าสุด
2. ค่าประจำเพลงยังต้องกด “จำ EQ เพลงนี้” ไม่ถูกบันทึกทับอัตโนมัติจากการหมุนลูกล้อ
3. BYPASS และ FLAT เปลี่ยนผ่านค่า Gain/Preamp/Output เป็น 8 ขั้น ตั้งเวลาระหว่างขั้น 20 ms ระยะจริงขึ้นกับการตอบสนอง UI ไม่ใช่ DSP ramp ระดับ sample และยังไม่รับประกันไร้เสียงคลิกบนฮาร์ดแวร์จริง
4. BYPASS ค่อย ๆ เปลี่ยนค่าเสียงไป unity แต่เก็บเส้น EQ เดิมไว้สำหรับเปิดกลับ การกดซ้ำระหว่างเปลี่ยนจะใช้เป้าหมายล่าสุด การปรับด้วยมือยกเลิกการเปลี่ยนที่ค้างอยู่
5. หน้าจัดการค่าประจำเพลงที่เปิดอยู่ป้องกันการซ่อนแผง EQ ทั้งอัตโนมัติและปุ่มย่อ เมื่อปิดหน้าต่างย่อยแล้วจึงย่อได้ตามปกติ
6. ปุ่มจัดแถวตามขนาดที่ต้องใช้จริง กลุ่ม Input อยู่ด้วยกัน ความสูงแผงปรับตามพื้นที่ควบคุมและจำกัดตามพื้นที่จอ

ยังต้องตรวจ Windows จริง: เสียง SoundFont/Crossfade ขณะปรับ, เสียงคลิก, Windows scaling 125–200%, การแสดงฟอนต์ไทย และการเปลี่ยนจอจริง ตัวชุดนี้เป็น Source Preview ไม่ใช่ EXE ที่สร้างและรับรองแล้ว
