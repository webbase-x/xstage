# Sound Studio — รุ่น 0.5.81

## สิ่งที่ปรับ
- พิมพ์ระดับเสียงต่อไฟล์แล้วกดบันทึกได้ทันที ไม่ต้องกด “ใช้ระดับนี้” ก่อน เมื่อเปลี่ยนไฟล์ที่เลือกจะตรวจและเก็บค่าที่แก้ไว้ด้วย หากค่าผิดจะให้แก้ก่อน
- โหลด ตรวจไฟล์ และปิดเสียงทดลองในเธรดเบื้องหลัง กดหยุดหรือปิดหน้าต่างได้ระหว่างโหลด หากไลบรารียังโหลดไม่เสร็จ ระบบจะคืนทรัพยากรเมื่อคำสั่งโหลดสิ้นสุด โดยไม่เริ่มเล่นโน้ตที่ถูกยกเลิก
- เลือกโน้ต MIDI 0–127 (60 = C4), โน้ตเดียว, ไล่ช่วงโน้ต หรือคอร์ดเมเจอร์ ทดลองจาก Preset ในไฟล์เดิม ไม่สร้างการจับคู่ถาวร
- เตือนก่อนปิดเมื่อยังไม่บันทึก เลือกบันทึก/ทิ้งการเปลี่ยนแปลง/กลับไปแก้ไขได้
- จำคำค้น ไฟล์ Bank Preset แท็บ และค่าทดลองเสียงเมื่อเปิดหน้าต่างซ้ำในโปรแกรมรอบเดียวกัน ไม่ได้บันทึกความจำหน้าจอข้ามการปิดโปรแกรม

## ตรวจเสียงเพลง
ไปแท็บ “ตรวจเสียงเพลง” เลือกไฟล์ MIDI/EMK ที่โปรแกรมรองรับ หรือเพลงปัจจุบัน ระบบอ่านข้อมูลเบื้องหลังแล้วเทียบช่อง MIDI, Bank MSB, Bank LSB และ Program กับไฟล์ SoundFont และการจับคู่ที่ตั้งไว้ในหน้าต่าง ผลตรวจส่งออก CSV ได้

- พบตรง: พบ Preset ตามหมายเลขในข้อมูลไฟล์
- ไม่พบตรง: ไม่มีหมายเลขนั้นในชุดเสียงที่อ่านได้ อาจเงียบหรือใช้เสียงสำรอง
- ต้องตรวจเพิ่มเติม/ตรวจไม่ครบ: เช่น Bank LSB, SFZ ไม่มีตาราง Preset, ไฟล์อ่านไม่ได้ หรือการจับคู่ไม่สมบูรณ์

รายงานนี้เป็นการตรวจข้อมูล ไม่ได้ดักสัญญาณเสียงจริง ไม่ยืนยันเสียงสำรองที่ BASS เลือก และไม่ครอบคลุมการแก้เสียงจาก Mixer หรือโหมด GS/XG/SysEx เฉพาะผู้ผลิต การมี Preset ไม่ยืนยันว่ามี Sample ครบทุกโน้ต จึงควรใช้การทดลองช่วงโน้ตประกอบ

## วิธีใช้งาน
1. เพิ่ม SoundFont ที่มีเสียงที่ต้องการเพียงไฟล์เดียวได้ ไม่ต้องแยกไฟล์เครื่องดนตรีไทย
2. เปิด “ใช้ทุกเสียงในไฟล์ตาม Bank / Program ของเพลง” หากต้องการให้เพลงเรียกตามหมายเลขเดิม
3. ทดลองเสียงในแท็บ “เสียงทั้งหมดในไฟล์” เลือกรูปแบบและโน้ตก่อนกดฟัง หยุดเพลงปัจจุบันก่อนทดลอง
4. หากเสียงบางชิ้นไม่ออก ให้ตรวจ MIDI กับ SoundFont และทดลองช่วงโน้ตที่เครื่องดนตรีนั้นมี
5. บันทึกเพื่อใช้กับเพลงถัดไป ไม่ตัดเพลงที่กำลังเล่น

## ตรวจบน Windows จริง
ยังไม่ได้ทดสอบเสียงกับอุปกรณ์ Windows ในสภาพแวดล้อมพัฒนานี้:
- ทดสอบไฟล์ SoundFont ที่ใช้จริง โดยเฉพาะเสียงไทยและกลองในหลาย Bank
- ทดลองไฟล์ใหญ่ กดหยุดระหว่างโหลด แล้วทดลองใหม่ ตรวจว่าไม่มีเสียงย้อนหลังหรือเสียงค้าง
- ทดลอง MIDI ที่ทราบว่า Bank/Program ตรงและไม่ตรง เทียบรายงานกับเสียงที่ได้ยิน
- ตรวจหน้าต่างที่ Windows Display Scale 100%, 125%, 150%, 200% และสองจอ
- เปิดเพลงต่อเนื่องอย่างน้อย 30 นาที รวมเปลี่ยนคิวและเมดเล่ย์ พร้อมบันทึกผลในเมนูรายงานตรวจระบบ

การตรวจ Tk scaling บน Linux ใช้ตรวจตำแหน่งปุ่มเบื้องต้น ไม่แทนผล Windows DPI หรือการฟังเสียงจริง
