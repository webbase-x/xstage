# Sound Studio — รุ่น 0.5.80

เปิดคลิกขวา → ระบบเสียง SoundFont

## ไฟล์เดียวใช้ได้ทุกเสียงที่มี
เลือก SoundFont แล้วเพิ่มไฟล์ SF2 เพียงครั้งเดียว เปิด “ใช้ทุกเสียงในไฟล์ตาม Bank / Program ของเพลง” แล้วบันทึก เพลงถัดไปจะใช้หมายเลขเสียงในเพลงเรียก Preset ที่มีในไฟล์ รวมเสียงดนตรีไทย เสียงสากล และชุดกลอง ไม่ต้องแยกไฟล์ตามเครื่องดนตรี

เพลงต้องเรียก Bank/Program ตรงกับชุดเสียงนั้น การมีเสียงระนาดอยู่ในไฟล์ไม่ได้ทำให้ทุกเพลงเปลี่ยนเป็นระนาดอัตโนมัติ และโปรแกรมไม่ได้เพิ่มเสียงที่ไฟล์ไม่มี จึงควรทดลองด้วยเพลงและ SoundFont ที่ใช้จริง ชุดเสียงบางชนิดที่ใช้ข้อกำหนดหรือการจับคู่เฉพาะผู้ผลิตต้องตรวจแยกตามไฟล์

โหมดนี้ข้ามการจับคู่กลุ่มเครื่องดนตรีที่เคยกำหนด แต่เก็บการจับคู่เดิมไว้ หากบันทึกจากเมนู SoundFont แยกเครื่องดนตรี จะกลับไปใช้การจับคู่นั้น การตั้งค่าเดิมไม่ถูกเปลี่ยนเองเมื่อเปิดหน้าต่าง

## หน้าต่างใหม่
- ชุดเสียง: เพิ่ม/นำออก เรียงลำดับ ลดระดับเสียงต่อไฟล์ และเลือกตามเสียงในเพลง
- เสียงทั้งหมดในไฟล์: ชื่อเสียง Bank และ Preset ค้นหาชื่อหรือกรอง Bank พร้อมปุ่มฟัง/หยุด
- คุณภาพ: อัตโนมัติหรือโปรไฟล์สำเร็จรูป จำนวนเสียงพร้อมกัน และบัฟเฟอร์
- เอฟเฟกต์: รีเวิร์บ/คอรัสตามเพลง หรือกำหนดเอง
- ทดสอบ: ทดลองเครื่องดนตรีพื้นฐานและวัดประสิทธิภาพสังเคราะห์เสียง

ปุ่มบันทึกและปิดอยู่ท้ายหน้าต่าง เมื่อพื้นที่ไม่พอเลื่อนดูเนื้อหาได้ สถานะบอกชัดว่าเลือก SoundFont หรือ Windows MIDI (Windows MIDI ไม่ใช้ไฟล์ SoundFont ที่เลือก)

## ทดลองเสียง
แท็บเสียงทั้งหมดในไฟล์อ่านรายชื่อที่มีจริง ไม่สร้างชื่อเครื่องดนตรีขึ้นเอง ค้นหาเช่น Ranat, Khim, Khaen หรือชื่อภาษาไทยที่ไฟล์เก็บไว้ ชื่อภาษาไทยแบบ UTF-8 รองรับแล้ว ชื่อในไฟล์เก่าที่ใช้รหัสอักขระอื่นอาจแสดงผิด การทดลองเรียก Bank/Preset ที่เลือกจากไฟล์นั้นโดยตรงและไม่บันทึกการจับคู่ชั่วคราว

หยุดเพลงปัจจุบันก่อนทดลอง ใช้ระดับเสียงเริ่มต้น −6 dB ต่อไฟล์ การบันทึกมีผลกับเพลงถัดไปเพื่อไม่ตัดเสียงเพลงที่กำลังเล่น SFZ ทดลองได้เป็นเสียงของไฟล์นั้น แต่ไม่มีตาราง Bank/Preset แบบ SF2 และต้องเก็บไฟล์ตัวอย่างเสียงประกอบให้ครบ

รายชื่อแสดงสูงสุด 1,000 เสียงต่อการค้นหา หากเกินให้เลือก Bank หรือค้นหาเพิ่ม ไม่มี SoundFont เชิงพาณิชย์หรือชุดเสียงดนตรีไทยบรรจุเพิ่มในรุ่นนี้

## การตรวจ
ตรวจตรรกะการโหลดหนึ่งไฟล์ให้ครอบคลุมทุก Preset, การส่ง Bank Select / Program Change, การทดลองเสียงตรง Preset, ชื่อ UTF-8 และการคืนค่าหากบันทึกไม่สำเร็จ พร้อมตรวจหน้าต่าง Tk บน Linux ยังไม่ได้ฟังเสียงเครื่องดนตรีไทยจริงจากอุปกรณ์ Windows ของผู้ใช้
