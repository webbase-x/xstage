# คิว เสียง และการแสดง — 0.5.45 Source Preview

เปิดจาก **คลิกขวา → เครื่องมือ → คิวและการแสดง**

## แทรกเพลงเข้าคิว
ค้นชื่อ/รหัส/ศิลปิน เลือกเพลง ระบุตำแหน่ง แล้วกดแทรกคิว โปรแกรมเพิ่มก่อนตำแหน่งนั้นโดยรักษาลำดับของคิวอื่นไว้
ในหน้าคิวมีปุ่ม “แทรกเพลง” และ “ประวัติ” เพิ่มด้วย เพลงที่แทรกใหม่เริ่มคีย์ 0 และความเร็ว 100%; แก้ชื่อผู้ร้อง/คีย์ของรายการนั้นได้ตามเดิม

## ประวัติการเล่น
เก็บเพลงที่เริ่มเล่นสำเร็จ 500 รายการล่าสุด พร้อมเวลา ผู้ร้อง คีย์ ความเร็ว และสถานะจบ/เปลี่ยนเพลง/เมดเล่ย์
เลือกเพิ่มท้ายคิวหรือแทรกเป็นคิวถัดไปได้ แต่ไม่ยกสิทธิ์หรือรหัสคำขอมือถือเดิมกลับมา
หากไฟล์หายหรือรหัสเพลงในฐานข้อมูลเปลี่ยนเป็นคนละไฟล์ จะให้ค้นหาใหม่เพื่อไม่เล่นผิดเพลง
ข้อมูลอยู่ใน Data/history.json โดยชุดสำรองสามไฟล์จากเมนูสำรองเดิมยังไม่รวมประวัติไฟล์นี้ หากต้องการเก็บประวัติด้วยให้สำรอง Data/history.json เพิ่ม

## ช่องเสียงร้อง / แทร็กเสียง
- WAV/MP3 ผ่าน BASS FX: เลือกสเตอริโอ หรือใช้เสียงต้นฉบับช่องซ้าย/ขวาส่งออกทั้งสองข้าง
- วิดีโอ/WMA ผ่าน Windows MCI: สั่งเปิด/ปิดช่องซ้ายหรือขวา และเลือกหมายเลขแทร็กเสียง 1–32 ได้เมื่อ codec รองรับ; ไม่ได้ตรวจพบจำนวนแทร็กหรือชื่อแทร็กอัตโนมัติ
- MCI เปิดเสียงเฉพาะด้านที่เลือก ไม่ได้คัดลอกเสียงด้านนั้นไปอีกลำโพงเหมือน BASS FX
- เมื่อ codec ไม่รองรับหรือไม่มีแทร็กนั้น จะแจ้งข้อผิดพลาด ไม่ถือว่าเปลี่ยนสำเร็จ
- ต้องเป็นไฟล์ที่แยกเสียงร้อง/ดนตรีไว้แล้ว ไม่ใช่ AI ลบเสียงร้องจากไฟล์สเตอริโอที่ผสมรวมมา
- ใช้เฉพาะเพลงปัจจุบัน เพลงถัดไปกลับไปใช้ค่าของไฟล์เดิม

## SoundFont แยกเครื่องดนตรี
เพิ่มไฟล์ SoundFont ในหน้าซาวด์ฟอนต์และบันทึกชุดเสียงก่อน จากนั้นเลือกกลุ่มเครื่องดนตรี GM และไฟล์ที่ต้องการ กด “ใช้กับกลุ่มที่เลือก” แล้วบันทึก
มี 16 กลุ่ม GM เช่น กีตาร์/เบส/เครื่องสาย และชุดกลอง Bank 128 โดยกลุ่ม GM ใช้ Bank 0
เสียงที่ไม่กำหนดใช้ลำดับ SoundFont เดิม การจับคู่ใช้ Program เดิม; หากไฟล์ไม่มี Program นั้น BASS อาจใช้ preset แรกของไฟล์
นี่คือการเลือก SoundFont ตามกลุ่มเครื่องดนตรี ไม่ใช่แยก SoundFont รายโน้ตกลอง และไม่ใช่แยกไลน์เสียงออกช่องของ Audio Interface
ใช้กับเพลงถัดไป หากนำ SoundFont ออกจากชุดและบันทึก การจับคู่ที่อ้างไฟล์นั้นจะคืนค่าตามลำดับเสียงเดิม

## เสียงเอฟเฟกต์หน้าเวที
มี 4 ปุ่มเริ่มต้น: ตบมือสังเคราะห์ แตรสั้น ระฆัง และกลองส่ง ทั้งหมดสร้างเป็นเสียงสังเคราะห์สำหรับโปรแกรมนี้
เลือกไฟล์ WAV/MP3 ของตนเองแทนแต่ละปุ่มได้ ความยาวไม่เกิน 60 วินาที ปรับความดังแยกจากเพลง และหยุดทั้งหมดได้
Ctrl+1–4 ใช้ขณะหน้าต่างเอฟเฟกต์อยู่ด้านหน้า เปิดพร้อมกันสูงสุด 4 เสียง; เมื่อเกินจะหยุดเสียงเก่าสุดก่อน
ปิดหน้าต่างหรือปิดโปรแกรมจะหยุดเอฟเฟกต์ ไม่แก้ไขไฟล์ต้นฉบับ

## เมดเล่ย์ / ต่อเพลง
เปิดใช้งาน กำหนด Mark Out 0–32 ห้อง MIDI และ Fade out/Fade in 0–10 วินาที
Mark Out คำนวณจาก tempo map และ time signature สำหรับ MIDI แบบ PPQN; เพลงสั้นกว่าจำนวนห้องที่เลือกจะเล่นจนจบแทนการข้ามทั้งเพลง
เลือกใช้ความเร็วของคิวถัดไป หรือคง BPM ของเพลงก่อนสำหรับ MIDI; จำกัดความเร็วตามเครื่องเล่น 50–150% จึงอาจคง BPM ไม่ได้ตรงเมื่อเกินช่วงนี้
WAV/MP3/วิดีโอ และ MIDI แบบ SMPTE ไม่ต่อก่อนจบด้วยจำนวนห้อง แต่ต่อเมื่อจบเพลง
เมื่อคิวว่างไม่ตัดเพลงก่อนจบ และเมื่อพักเพลงจะไม่เลื่อนคิว

**ขอบเขต:** เป็นการลดเสียงเพลงเดิมแล้วเปิดเพลงใหม่และค่อยเพิ่มเสียง ไม่ใช่ Crossfade สองเพลงพร้อมกัน ยังมีเวลาโหลดเพลง/ชุดเสียงระหว่างเปลี่ยนเพลง และไม่ได้คง pattern จังหวะกลองเดิมข้ามเพลง (Keep Rhythm เต็มรูปแบบ)

## โลโก้แทนไอคอนขนนก
ใช้โลโก้ X-Stage เดิมเป็นไอคอนหน้าต่าง และสร้าง assets/xstage.ico หลายขนาดสำหรับ EXE/แถบงาน
ต้องสร้าง EXE ใหม่ด้วยตัวสร้างของรุ่นนี้เพื่อเปลี่ยนไอคอนในไฟล์โปรแกรม EXE เก่าจะไม่เปลี่ยนตามการคัดลอกไฟล์ภาพ

## สถานะทดสอบ
ตรวจ logic คิว/ประวัติ, mapping, DSP ด้วย buffer จำลอง, คำสั่ง MCI จำลอง, Mark Out/Fade, จำกัดเสียง FX และโครงสร้าง ICO แล้ว
ยังไม่ได้รัน Windows GUI, native BASS/MCI/waveOut หรือฟังเสียงจริงของรุ่นนี้ และยังไม่ได้สร้าง EXE ในสภาพแวดล้อมนี้
