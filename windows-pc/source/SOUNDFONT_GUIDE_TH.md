# X-Stage Karaoke v0.5.1 — ระบบเสียง SoundFont

สถานะ: โค้ดพร้อมสำหรับทดสอบบน Windows; ชุด Source Preview ไม่มี EXE รุ่นใหม่และไม่มี SoundFont เชิงพาณิชย์

## เปิดใช้งาน

1. สร้าง EXE ด้วย Build-Windows.cmd บน Windows x64 ที่ติดตั้ง Python พร้อม Tcl/Tk
2. รัน Setup-Audio.ps1 ในโฟลเดอร์ EXE ที่สร้าง เพื่อรับ BASS/BASSMIDI x64 จากผู้พัฒนา
3. คลิกขวา → ซาวด์ฟอนท์ → เลือก SoundFont
4. เพิ่มไฟล์ .sf2 หรือ .sfz ของตนเอง เช่น ไฟล์ในโฟลเดอร์ SoundFont ของคลังเพลงเดิม
5. เริ่มจากไฟล์ GM ที่มีเสียงเครื่องดนตรีครบ 128 เสียงและชุดกลอง แล้วเลือกโปรไฟล์ “คุณภาพสูง”
6. ถ้ายังไม่มีเพลงโหลดอยู่ กดทดลองเปียโน/กีตาร์/เบส/กลอง แล้วบันทึกสำหรับเพลงถัดไป
7. ทดสอบเพลง MIDI/NCN/EMK หลายแนวก่อนนำไปใช้งานจริง จากนั้นติดตั้งด้วย Install-to-D.cmd ภายใน dist/XStageKaraoke

SFZ อ้างถึงไฟล์เสียงภายนอก ต้องเก็บ sample และโฟลเดอร์เดิมไว้ครบ การตรวจไฟล์ก่อนเล่นยังไม่ได้ยืนยัน sample ภายนอกทุกไฟล์
MP3/WAV/วิดีโอเป็นเสียงบันทึก จึงไม่เปลี่ยนเครื่องดนตรีด้วย SoundFont
ไม่มีการโหลด SoundFont ที่ป้องกันด้วยฮาร์ดล็อกหรือถอดระบบป้องกันของโปรแกรมอื่น

## ค่าระบบเสียง

| ค่า | คุณภาพสูง | สมดุล | ประหยัด CPU |
|---|---:|---:|---:|
| การแปลง sample | Sinc 16-point | Sinc 8-point | Linear |
| เสียงตัวอย่างพร้อมกัน | 512 | 256 | 128 |
| บัฟเฟอร์ | 80 ms | 60 ms | 100 ms |
| การสังเคราะห์ | 48 kHz / stereo float32 | 48 kHz / stereo float32 | 48 kHz / stereo float32 |

จำนวนเสียงหมายถึง sample voices ของ synthesizer ไม่ใช่ช่องเอาต์พุตมิกเซอร์
บัฟเฟอร์เป็นค่าที่ร้องขอจาก BASS ไม่ใช่การรับประกัน latency รวมของอุปกรณ์เสียง
ไฟล์ที่มีความละเอียดสูงหรือขนาดใหญ่กว่าไม่ได้ทำให้เสียงดีกว่าเสมอไป ควรฟังความสมดุลของแต่ละเครื่องดนตรีจริง

ไฟล์ที่อยู่บนสุดมีความสำคัญก่อนเมื่อมี bank/program ซ้ำกัน เสียงที่ไม่มีจะค้นจากไฟล์ถัดไป
ตั้ง gain เริ่มต้น −6 dB เพื่อเผื่อระดับเสียง ลดได้ถึง −24 dB; ไม่เพิ่มเกิน 0 dB
ระบบนี้ยังไม่มี brick-wall limiter หรือ loudness normalization จึงควรลด gain/master ถ้าเสียงรวมแตก

ค่ารีเวิร์บ/คอรัสเริ่มต้นใช้ตามเพลง เลือก “กำหนดเอง” เพื่อส่งค่า CC91/CC93 เท่ากันทั้ง 16 แชนเนล
รีเวิร์บช่วยเพิ่มความก้อง คอรัสเพิ่มความหนาของเสียง ค่ามากเกินไปอาจทำให้เสียงไม่ชัด
การตั้งค่าถูกเก็บใน Data/settings.json ภายใต้ soundfont_audio และนำมาใช้เมื่อเริ่มเพลงถัดไป
การตั้งค่า soundfont แบบไฟล์เดียวจากรุ่นเก่ายังคงอ่านได้

## สิ่งที่ทดสอบแล้วและสิ่งที่รอ Windows

ทดสอบด้วย BASS/BASSMIDI ทางการบน Linux ในโหมด offline: สร้าง stereo float PCM ได้จริง, ระดับ −12 dB เบากว่า −6 dB ตามสัดส่วน, เอฟเฟกต์เปลี่ยนเสียง, ปิดและเปิดซ้ำได้
ใช้ SF2 คลื่นไซน์ที่สร้างขึ้นเพื่อทดสอบเท่านั้น ไม่ใช้ผลนี้อ้างว่า SoundFont ดนตรีทุกชุดมีคุณภาพดีหรือครบทุกเสียง
ทดสอบลำดับหลายไฟล์/คืนทรัพยากรเมื่อโหลดผิดพลาด/การรักษาเอฟเฟกต์ผ่านตัวจำลอง native API
ยังรอทดสอบ GUI Windows, เสียงจากลำโพงจริง, การร้องตรงเนื้อเพลงภายใต้บัฟเฟอร์ และ SoundFont ขนาดใหญ่ของผู้ใช้
ยังไม่ได้เพิ่ม ASIO แยกไลน์, VST หรือการประมวลผลไมโครโฟนในรุ่นนี้

## Enter ในผลค้นหา

มีเพลงกำลังเล่น/พัก/หยุดอยู่: เพิ่มเพลงที่เลือกท้ายคิว แม้คิวรอว่าง
ไม่มีเพลงปัจจุบันหรือเพลงเดิมจบแล้ว และคิวรอว่าง: เล่นเพลงที่เลือกทันที
Ctrl+Enter: เล่นผลค้นหาทันทีตามคำสั่งผู้ใช้
