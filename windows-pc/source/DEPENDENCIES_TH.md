# ติดตั้งพร้อมตรวจส่วนประกอบ — 0.5.73

แตก ZIP ทั้งชุดแล้วเรียก Install-to-D.cmd ตัวติดตั้งจะทำงานตามลำดับ:
1. ตรวจ Windows 10/11 แบบ x64 และเปิด PowerShell แบบ 64 บิต
2. ตรวจ Visual C++ Runtime; หากขาด/เก่า ดาวน์โหลดตัวติดตั้งที่ตรวจลายเซ็น Microsoft แล้วติดตั้ง
3. ตรวจ BASS, BASSMIDI, BASS FX; ดาวน์โหลดจากผู้พัฒนาเมื่อขาดหรือโหลดไม่ได้
   ตรวจ PE x64 และโหลด/API รุ่น 2.4 ในพื้นที่ชั่วคราวก่อนเปลี่ยนไฟล์เดิม
4. หากเป็นชุดซอร์ส ตรวจ Python x64 3.11–3.14 พร้อม Tk/venv/SSL
   หากไม่มี ดาวน์โหลด Python 3.14.10 x64 ตรวจลายเซ็นและ SHA256 แล้วติดตั้งสำหรับผู้ใช้ปัจจุบัน
5. เตรียม environment แยกและติดตั้ง Pillow, NumPy, qrcode, SoundCard/CFFI และ PyInstaller
   ตรวจ pip check, import และ native libraries ก่อนสร้าง EXE
6. ทดสอบโค้ด สร้าง EXE ตรวจไลบรารีจาก EXE ที่สร้างจริง แล้วจึงติดตั้งลง App/Source
7. สำรองไฟล์โปรแกรมก่อนอัปเดต รักษา Data/เพลงเดิม ตรวจ EXE อีกครั้งหลังคัดลอก
   หากอัปเดตล้มเหลว ใช้ระบบกู้คืนไฟล์โปรแกรมเดิม

ไฟล์ที่ถูกต้องอยู่แล้วจะนำกลับมาใช้ได้ ส่วนดาวน์โหลดเก็บ cache สำหรับการเรียกครั้งถัดไป
รายการใน offline/README.txt ใช้เตรียมส่วนประกอบไว้ล่วงหน้าได้ ต้องครบและตรงสถาปัตยกรรม
หาก ZIP/cache เสีย ระบบลบเฉพาะไฟล์แคชเสียแล้วดาวน์โหลดใหม่และตรวจซ้ำ ไฟล์ offline เสียจะเก็บต้นฉบับไว้และดาวน์โหลดแทน หากไม่มีอินเทอร์เน็ตจะรายงานสาเหตุให้แก้แพ็กเกจ offline
ตัวติดตั้งไม่ปิดการตรวจความปลอดภัย Windows และไม่รีสตาร์ตเครื่องเอง
หาก Windows ขอสิทธิ์ติดตั้ง Runtime ต้องยืนยัน UAC; หากปฏิเสธ จะหยุดพร้อมเหตุผล

## รายงาน
- บันทึกติดตั้ง: %LOCALAPPDATA%\XStageKaraoke\Logs\install-*.log
- ผลตรวจไลบรารี: App\dependency-report.json และ dependency-report.json ในโฟลเดอร์ซอร์ส/ชุด build
- ผล unit tests: build-tests.log
- ซ่อมส่วนประกอบ: รัน Install-to-D.cmd ซ้ำ หรือ Setup-Audio.cmd ที่โฟลเดอร์ติดตั้ง

## ขอบเขตที่ต้องระบุให้ชัด
รองรับ Windows 10/11 x64 ไม่รับประกัน Windows ทุกเวอร์ชัน/ARM64/32 บิต
การตรวจไลบรารีไม่ได้ยืนยันคุณภาพเสียงหรือการทำงานของอุปกรณ์จริง
SoundFont (.sf2/.sfz), เพลง และไฟล์ Fx เป็นเนื้อหาที่ผู้ใช้เลือก ไม่ใช่ไลบรารีที่ติดตั้งแทนได้
ไดรเวอร์การ์ดเสียง, สิทธิ์ไมโครโฟน/เครือข่าย, Firewall และ codec วิดีโอเฉพาะไฟล์ขึ้นกับเครื่อง
ไม่มีการติดตั้ง codec pack, VST, ASIO หรือ DMX ที่ระบบยังไม่ได้รองรับ
EQ รุ่นนี้ไม่ต้องใช้ Equalizer APO

ทดสอบ PowerShell parser/พฤติกรรม offline และ PE; ดาวน์โหลด ZIP ทางการทั้ง 3 ชุดและยืนยัน x64 ได้
ยังไม่ได้รันทดสอบติดตั้ง Python/UAC/native audio บน Windows จริง
