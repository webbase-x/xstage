## เพิ่มเติมสำหรับ 0.5.45

- แทรกเพลงระหว่างคิวที่มีเพลงชื่อซ้ำ แต่คีย์/ผู้ร้องต่างกัน ตรวจว่าคิวอื่นไม่เปลี่ยน
- เล่นจบ เปลี่ยนเพลงกลางคัน ปิดเปิดโปรแกรม แล้วเรียกจากประวัติเข้าคิว ตรวจคีย์/ความเร็ว/ผู้ร้องและไฟล์ที่ถูกต้อง
- WAV/MP3 สเตอริโอทดสอบที่ L/R มีคนละเสียง ทดลองเลือกซ้าย/ขวา และคืนสเตอริโอ
- วิดีโอทดสอบหลาย audio stream: เลือกแต่ละแทร็ก แล้วลองหมายเลขที่ไม่มี ต้องแจ้งข้อผิดพลาด; codec บางชนิดไม่รองรับ
- SoundFont สองไฟล์ที่เสียงแตกต่างชัดเจน เลือกกีตาร์จากหนึ่งไฟล์/กลองจากอีกไฟล์ แล้วฟังเพลงจริง รวมกรณีนำไฟล์ออกจากชุด
- ยิง FX ระหว่างเพลง/บันทึก/รีโมท ทดสอบซ้อน 4 เสียง Ctrl+1–4 และหยุดทั้งหมด
- เมดเล่ย์: MIDI 4/4, 3/4 และเปลี่ยน tempo/time signature กำหนด Mark Out 1/2 ห้อง ตรวจ Fade พัก/เล่นต่อ คิวว่าง และไฟล์ถัดไปเสียหาย
- ฟังความต่อเนื่องและเวลาโหลดจริง; รุ่นนี้ไม่รับรอง gapless หรือ Crossfade สองเครื่องเล่น

# ตรวจบน Windows เครื่องจริง — รุ่น 0.5.42

สถานะ: ยังไม่ได้รันทดสอบบนเครื่อง Windows หรืออุปกรณ์เสียงของผู้ใช้จากแชตนี้

## หน้าต่างรีโมท
1. เปิด เครื่องมือ → รีโมตมือถือ แล้วทำตามขั้น เชื่อมต่อ → ตั้งค่า → พร้อมใช้งาน
2. ที่หน้าตั้งค่า ย่อหน้าต่างและขยายกลับ ตรวจว่าหัวข้อย้ายทั้งกลุ่ม มีเลขหน้า และค่าที่เลือกยังอยู่
3. เปิดตั้งค่าเพิ่มเติม ตรวจทุกหน้าจนถึงปุ่มบันทึกและเปิดรีโมท
4. ใช้มือถือบน Wi-Fi เดียวกัน สแกน QR ใส่ชื่อ ขอเพลง และดูคิว
5. หากหน้าต่างกระพริบ ค้าง ตัดข้อความ หรือปุ่มหาย ให้ส่งภาพหน้าต่างพร้อมค่า Windows Display scale และความละเอียดจอ

## SoundFont และเสียงจริง
1. กด F7 ยกเลิกเพลงก่อน เปิด ซาวด์ฟอนท์ → ชุดเสียง เลือก SF2 ที่ใช้จริง
2. ไปแท็บ ทดสอบ เลือกเปียโน กีตาร์ เบส และกลอง แล้วกดทดลองเสียงทีละชนิด
3. ฟังว่ามีเสียงครบ เสียงแตก หรือกระตุกหรือไม่ ระวังระดับเสียงเริ่มต้น
4. ปุ่มวัดประสิทธิภาพสังเคราะห์เสียงทดสอบการสร้าง PCM ไม่ใช่การวัดความหน่วงที่ลำโพง
5. บันทึกค่า แล้วเล่นเพลง MIDI ที่เครื่องเคยกระตุกอย่างน้อย 3 เพลง สลับหน้ารีโมทระหว่างเล่น
6. ส่งชื่อ SoundFont, อุปกรณ์เสียง, รุ่น Windows และอาการที่ได้ยิน รวมผล benchmark ถ้ามี

## บันทึกเสียงจริง
1. เปิด เครื่องมือ → บันทึกเสียง เลือกไมค์หรือ Stereo Mix ที่ต้องการ
2. เริ่มบันทึก WAV พูดหรือเปิดเสียงตัวอย่างประมาณ 10 วินาที แล้วกดจบบันทึก
3. เปิด WAV ด้วยโปรแกรมเล่นเสียง ตรวจว่าได้ยินเสียง ไม่มีช่วงหาย และความยาวใกล้เคียงที่บันทึก
4. หากเลือกไมค์จะเป็นเสียงจากไมค์ ไม่ได้ผสมดนตรีในโปรแกรมให้อัตโนมัติ
5. บันทึกชื่ออุปกรณ์ input และข้อผิดพลาดที่แสดงถ้ามี

## กู้คืนข้อมูล
1. ใช้ เครื่องมือ → สำรองข้อมูล ก่อนทดลอง และเก็บโฟลเดอร์สำรองไว้นอกโฟลเดอร์ติดตั้ง
2. หยุดเพลง การบันทึก รีโมท และงานสร้างรายการ ปิด X-Stage หน้าต่างอื่นทั้งหมด
3. เครื่องมือ → กู้คืนข้อมูล → เลือกโฟลเดอร์สำรอง ตรวจจำนวนเพลง/คิว แล้วยืนยัน
4. เปิดโปรแกรมใหม่ ตรวจเพลง คิว และการตั้งค่า
5. ข้อมูลก่อนกู้คืนเก็บใน Data/restore-safety-... ตามตำแหน่งที่แจ้งหลังสำเร็จ
6. ชุดสำรองไม่มีไฟล์เพลง SoundFont หรือ DLL; ไฟล์เหล่านี้ต้องอยู่ที่เดิม
