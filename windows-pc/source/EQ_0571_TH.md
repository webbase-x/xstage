# EQ X-Stage Karaoke 0.5.71

## เปิดและย่อเก็บ
เลื่อนเมาส์ชิดขอบล่างของจอคาราโอเกะ แล้วกด EQ บนแถบควบคุม
หน้าต่างเป็นแร็ก 31 ช่อง ขนาดเริ่มต้นไม่เกิน 1400 × 490 และปรับตามพื้นที่จอ
กด ย่อเก็บ หรือ Escape เพื่อกลับจอร้อง; กด EQ เพื่อเรียกคืนค่าเดิม
เมื่อเมาส์เคยเข้าแล้วออกจากหน้าต่าง 1.2 วินาที จะย่อเก็บอัตโนมัติ กด ตรึง เพื่อค้างไว้
แถบควบคุมด้านล่างซ่อนเมื่อเมาส์ออก ไม่แสดงเพียงเพราะขยับเมาส์กลางจอ
ระหว่างสแกนเพลงยังแสดงสถานะงาน และสามารถตรึงแถบได้

## ปรับเสียง
31 ความถี่คงที่ 20 Hz–20 kHz, 1/3 octave, ซ้าย–ขวาเชื่อมกัน, ±12 dB
ลากสไลเดอร์แล้วปล่อยเพื่อใช้ค่า; ดับเบิลคลิกคืน 0 dB
เลือกช่องด้วยลูกศรซ้าย/ขวา ปรับทีละ 0.5 dB ด้วยขึ้น/ลงเมื่อโฟกัสที่แผง EQ
INPUT ลดระดับก่อน EQ เพื่อเผื่อการบูสต์; BYPASS ข้ามการปรับ; FLAT คืนค่ากลาง
บันทึก/นำเข้า Preset JSON 31 ช่องได้ ค่าระบบ 8 แบนด์เดิมไม่แปลงโดยประมาณ
หากมีค่า EQ เดิมอยู่ กดใช้ค่าจึงเปลี่ยนเป็น 31 ช่อง (เริ่มต้น Flat)
ย่านที่สูงถึง/เกิน Nyquist ของสตรีมจะไม่เปิดตัวกรอง

## ขอบเขต
EQ มีผลกับเพลงผ่าน BASS และเพลงท้ายในช่วงเมดเล่ย์ที่ใช้ BASS
ไม่ได้ปรับเสียงทั้งหมดของ Windows และไม่ได้ปรับไมค์ภายนอก คีย์บอร์ดหรือ FX ที่ใช้ทางออกอื่น
หากเคยใช้โหมด Windows จะปิดเฉพาะไฟล์ EQ ที่ X-Stage จัดการก่อนเปิด EQ เพลง
ไม่ลบ Equalizer APO หรือค่าปรับของโปรแกรมอื่น

## ไฟจริง
ไฟรายช่องเป็นพลังงานดิจิทัล RMS ในย่านนั้น จากเสียงรวม Windows ที่อุปกรณ์ออกเสียงเริ่มต้น
ไฟท้าย L/R เป็น Sample Peak แนวตั้ง ช่วง −60 ถึง 0 dBFS พร้อม Peak Hold และ CLIP
ไม่รวมอุปกรณ์ออกเสียงอื่น ไม่ใช่ SPL, True Peak หรือเครื่องตรวจเสียงหอน
EQ ปรับเพลง X-Stage แต่ไฟสามารถขยับจากโปรแกรมอื่นบนอุปกรณ์เดียวกันได้
วิเคราะห์เป็นหน้าต่างประมาณ 0.68 วินาที อัปเดตสูงสุดประมาณ 10 ครั้ง/วินาที
เมื่อไม่มีสิทธิ์/อุปกรณ์/สัญญาณที่อ่านได้ จะรายงานสถานะและไม่สร้างไฟจำลอง
ย่อหน้าต่างแล้วหยุดจับเสียงเพื่อลดภาระ
