# X-Stage Karaoke Online — แถบสถานะตรงแนว R17

ปรับเฉพาะ UI หน้า 3/3 ต่อจาก Compact Online R16:

- รวมแถบ **แปลงเพลง / อัปโหลด / ฐานเว็บ / Drive ใช้จริง / เมื่อซิงค์ครบ** ในตารางแสดงผลเดียวกัน
- ป้ายชื่อซ้ายอยู่แนวเดียวกัน แถบทั้งห้ากว้างเท่ากันและเริ่ม–สิ้นสุดตรงกัน
- เปอร์เซ็นต์/สถานะทุกแถวอยู่คอลัมน์เดียวกันและชิดขวา
- คงการใช้สีตามเปอร์เซ็นต์จริง ความจุ Google Drive และระบบซิงค์/ซ่อม/กู้คืนเดิม
- ไม่มี Scrollbar และไม่เพิ่มข้อความอธิบายในหน้า 3

## ผลตรวจ

- ตรวจตำแหน่ง x และความกว้างของ Tk `ttk.Progressbar` และคอลัมน์สถานะทั้ง 5 แถบที่ขนาดหน้าต่าง 680×460, 480×380, 320×310 ด้วย GUI จำลอง
- รันทดสอบ UI และ Google Drive Storage ที่เกี่ยวข้องได้โดยไม่พบ Failure/Error
- ยังไม่ได้สร้างหรือทดลอง EXE บน Windows จริง ต้องให้ Windows Build Gate ตรวจครบ

## การติดตั้ง

1. สำรอง `D:\newKaraoke\Data` แล้วแตก Source R17 เป็นโฟลเดอร์ใหม่ หรือแตก Hotfix R17 ลงบนซอร์ส R16
2. รัน `Verify-Windows-0948.cmd` ให้ผ่าน แล้วจึง `Build-Windows.cmd`
3. เปิดเมนูคลิกขวา X-Stage Karaoke Online → ไปหน้า 3/3 ตรวจว่าแถบทั้ง 5 ตรงกัน

ไม่มีการเปลี่ยนฐานเพลง, Google OAuth, และไฟล์บน Google Drive
