# EQ X-Stage Karaoke 0.5.72

## หน้าต่างและลูกล้อ
หน้าต่าง EQ ไม่มีไตเติลบาร์และปุ่มตรึง ใช้ปุ่ม - มุมขวาบนหรือ Escape เพื่อย่อเก็บ
ลากบริเวณชื่อ EQ เพื่อย้ายหน้าต่าง เมาส์ออกจากหน้าต่างจะย่อเก็บตามเดิม
เรียกคืนโดยเลื่อนเมาส์ชิดขอบล่างของจอร้องแล้วกด EQ
คลิกเลือกช่องที่ชื่อความถี่หรือสไลเดอร์ แล้วหมุนลูกล้อขึ้น/ลงเพื่อเพิ่ม/ลดทีละ 0.5 dB
ช่วง -12 ถึง +12 dB รองรับลูกล้อ Windows และ Linux; เหตุการณ์ลูกล้อบนแผง EQ ไม่ส่งไปปรับเสียงหลัก
ลากสไลเดอร์แล้วปล่อยยังใช้ได้เช่นเดิม

## แถวพรีเซ็ต 5 ตัวควบคุม
1. พรีเซ็ต: Flat, นุ่มนวล, เบสกระชับ, สดใส, เปิดพื้นที่ให้เสียงร้อง, Pop, Rock, Dance
   เป็นค่าที่ออกแบบสำหรับ X-Stage ไม่ใช่สำเนาของ Winamp/Spotify/Apple Music
2. ความเข้ม 0–100%: ปรับจาก Flat ไปถึงค่าพรีเซ็ตต้นแบบโดยไม่คูณซ้ำสะสม
3. ชดเชยระดับเสียง: ประเมินการบูสต์รวมของตัวกรอง 31 ช่อง ลด INPUT และเผื่อ 1 dB
   ทำเมื่อเลือก/ปรับความเข้ม/ติ๊กชดเชย ไม่ปรับความดังตามเสียงเพลงตลอดเวลา
   ไม่ใช่ Limiter ไม่รับประกันการป้องกันคลิปหรือแก้เสียงหอน
   การปรับแต่ละช่องเองยังคงเป็นค่าที่ผู้ใช้ควบคุม; กดชดเชยอีกครั้งเมื่อต้องการคำนวณใหม่
4. A/B: สลับสองชุดค่า เปิดหน้าต่างครั้งแรกทั้งสองชุดเริ่มจากค่าเดียวกัน
   การแก้ไขจะเก็บในชุดที่แสดงอยู่ อีกชุดคงเดิม สามารถสลับไปแก้ทั้งสองชุดได้
5. บันทึกพรีเซ็ต: ตั้งชื่อและเก็บไว้ในโปรแกรม เลือกคืนได้ในรายการที่มีดาว
   ชื่อซ้ำจะถามก่อนบันทึกทับ; ส่งออก/นำเข้า JSON ใช้ย้ายเครื่องได้

การเปลี่ยนพรีเซ็ต/A–B ใช้การไล่ค่าประมาณ 140 ms เพื่อลดการเปลี่ยนฉับพลัน
ไม่ใช่การเปลี่ยนแบบ sample-accurate และยังต้องฟังทดสอบกับ BASS/อุปกรณ์จริง
หากพื้นที่แคบ แถวพรีเซ็ตจะแบ่งสองแถวเพื่อให้เห็นปุ่มครบ

## ขอบเขตและการตรวจรับ
EQ ปรับเพลงและเพลงต่อคิวที่ผ่าน BASS ไม่ใช่ EQ เสียงรวม Windows หรือไมค์ภายนอก
มิเตอร์ยังอ่านเสียงรวม Windows ของอุปกรณ์เริ่มต้นเดียวกันตามรุ่น 0.5.71
ไม่ใช่ระบบ Auto EQ จูนห้อง: งานนั้นต้องมีการวัดเสียงจากลำโพงจริง

511 tests: ผ่าน 505 ข้าม 6 บน Linux; ตรวจ GUI เรื่อง preset, headroom, A/B,
ลูกล้อ, ขัดจังหวะการไล่ค่า, บันทึกชื่อ, ความเข้ม, ย่อ/เรียกคืน, ขนาดเล็ก และปิดหน้าต่าง
ยังไม่ได้ทดสอบเสียงจริง ไดรเวอร์ ฟอนต์/DPI และการติดตั้ง EXE บน Windows
