# X-Stage Karaoke Online — R18.1 Thai Titles + One Bar + ETA

รุ่นแก้ UI จาก **Turbo Sync R18** เท่านั้น ไม่ใช่ระบบซิงค์ใหม่

## สิ่งที่เปลี่ยน

1. หัวเรื่อง `ขั้นตอน 1/3`, `2/3`, `3/3` ใช้ `Tahoma` แบบหนา ซึ่งรองรับอักษรไทยบน Windows; ชื่อบัญชีที่เน้นตัวหนาใน Wizard เปลี่ยนตามด้วย
2. หน้า `3/3` แสดงความคืบหน้าเพียง **1 แถบเปอร์เซ็นต์รวม** ส่วนโควตา Drive จริง/โควตาคาดการณ์ยังอยู่ด้านล่างในรูปแบบข้อความพร้อมเปอร์เซ็นต์และพื้นที่ใช้งาน ไม่สร้างแถบเพิ่ม
3. เพิ่มเวลาคาดว่าจะเสร็จและเวลาคงเหลือโดยอิงความเร็วที่ **ทำเพลงเสร็จจริง** อย่างน้อย 3 เพลงและติดตามไม่น้อยกว่า 8 วินาที จึงไม่เดาตั้งแต่เริ่มงาน
4. แถบรวมใช้ 0–95% จากเพลงที่ประมวลผลครบแล้ว, 95–99% ในช่วงตรวจ Integrity เมื่อมีรายงานจำนวนที่ตรวจจริง, และ 100% **หลังงานยืนยันสำเร็จโดยไม่มีไฟล์เสีย/ตกค้าง** เท่านั้น การแบ่งช่วงเปอร์เซ็นต์เป็นเพียงการแสดงภาพขั้นตอน ไม่ใช่อัตราส่วนเวลา
5. ตอนเตรียม SoundFont, ตรวจฐานเพลง, อัปโหลดที่ไม่มีจำนวนยืนยัน, ติดขัด Google Drive, และตรวจฐานเว็บที่ประเมินไม่ได้ จะบอกตรง ๆ ว่ายังประเมินเวลาเสร็จไม่ได้
6. การประมาณเวลาช่วงเพลงอาจคลาดเคลื่อน และการตรวจ/เผยแพร่ฐานเว็บขั้นท้ายอาจทำให้ใช้เวลาเพิ่ม; ถ้าหยุดหรือเริ่มรอบใหม่จะรีเซ็ตค่าประเมิน ไม่แสดง 100% ผิด ๆ

## ส่วนที่ไม่เปลี่ยน

- Workers / Streaming Pipeline R18 / upload concurrency / Resume upload / SQLite Journal / Catalog, Google OAuth, โครงสร้าง Drive, ชื่อเพลง, รูปแบบเพลง, และฐานข้อมูล
- การเผยแพร่เพลงชุดแรกก่อนทั้งคลังเสร็จ, ตรวจคู่ M4A+Lyrics JSON, นโยบายคงไฟล์ต้นฉบับ
- กลไกควบคุมหยุด กู้คืน แล้วทำต่อ; ไม่จำเป็นต้องแตก ZIP บน Google Drive

## ไฟล์เปลี่ยน

- `karaoke/online_wizard.py` — UI หน้า 1–3 / แถบเดียว / โควตาข้อความ / ETA
- `karaoke/online_eta.py` — ตัวประมาณเวลาแยกจากงานอัปโหลด
- `karaoke/ui.py` — ส่ง feedback ที่มีจริงให้หน้า UI และแก้หัวเรื่อง hidden legacy view
- ไฟล์ทดสอบ GUI และ ETA ที่เกี่ยวข้อง
