# X-Stage Karaoke 0.5.76 — ตรวจระบบและเก็บผล Windows

## รายงานไฟล์เดียว
คลิกขวา → เครื่องมือ → รายงานตรวจระบบ / ผลทดสอบ Windows
เลือกผลตามที่ได้ทดสอบจริง และใส่รายละเอียดก่อนกด “สร้างรายงานไฟล์เดียว…”
รายงาน JSON รวมรุ่นโปรแกรม ระบบปฏิบัติการ สถานะไลบรารี ชื่อลำโพง/อุปกรณ์ขาออก ผลซ่อมล่าสุด และผลทดสอบที่ผู้ใช้ระบุ
การสร้างรายงานไม่เล่นเสียง ไม่เปลี่ยนอุปกรณ์หรือการตั้งค่า และไม่รับรองคุณภาพเสียง ผลที่ยังไม่ได้ตรวจคงเป็น “ยังไม่ทดสอบ”
รายงานเก็บในตำแหน่งที่เลือก ไม่ส่งออกทางเครือข่ายเอง อาจมีชื่ออุปกรณ์และตำแหน่งติดตั้ง แต่ไม่รวมรหัสรีโมท การตั้งค่าทั้งชุด หรือฐานรายการเพลง
หากตรวจไม่เสร็จภายใน 90 วินาทีจะแจ้งไม่สำเร็จ ตรวจไดรเวอร์/อุปกรณ์แล้วลองใหม่

## ขั้นตอนทดสอบด้วยเครื่องจริง
1. สำรองข้อมูลก่อนทดสอบ เลือกเพลง SoundFont, WAV/MP3 และวิดีโอที่ใช้จริง
2. เล่นต่อเนื่องอย่างน้อย 30 นาที พร้อมใช้งานรีโมทและบันทึกเสียง จดเวลา อาการกระตุก/ค้าง รุ่นการ์ดเสียง และ SoundFont ที่ใช้ เปิดฟังไฟล์บันทึกตรวจต้น-กลาง-ท้าย
3. เพลง A บันทึก EQ เฉพาะเพลง เพลง B ไม่บันทึก เปลี่ยน A → B → A และตรวจว่า B ใช้ค่ากลาง A เรียกค่าที่จำไว้ ลองข้ามคิวและ Crossfade ฟังว่าความดังผิดปกติหรือไม่
4. ปรับ EQ, BYPASS และ FLAT ระหว่างเล่น ตรวจเสียงคลิกและเสียงขาด การเปลี่ยนผ่านใช้เวลา UI จึงต้องฟังจริง
5. ทดสอบ Windows scaling 125%, 150%, 200% ตามที่เครื่องรองรับ ตรวจ EQ, Mixer, บันทึกเสียงและรีโมทว่าปุ่มครบ ข้อความไม่ทับ เปิดหน้าต่างย่อยแล้วย่อ/เรียกกลับ สลับจอถ้ามี
6. ทดสอบติดตั้งบนเครื่องสำรองหรือ VM Windows ที่สะอาด แล้วอัปเดตเครื่องทดสอบ ตรวจรายการเพลง คิว พรีเซ็ต และ EQ ประจำเพลงว่ายังอยู่ ไม่ควรใช้เครื่องงานแสดงจริงเป็นเครื่องทดลองติดตั้ง
7. บันทึกผลทีละหมวดและสร้างรายงานแนบกลับมาวิเคราะห์ หากหมวดใดตรวจไม่ครบให้เลือก “ยังไม่ทดสอบ” พร้อมหมายเหตุ

## ตรวจและซ่อมส่วนประกอบ
คลิกขวา → เครื่องมือ → ตรวจและซ่อมส่วนประกอบ
ระหว่างตรวจมีแถบแสดงว่ากำลังทำงาน กด “ส่งออกรายงาน…” ได้
การซ่อมต้องปิดโปรแกรมก่อน หน้าต่างซ่อมแสดง 5 ขั้น: รอปิด → ส่วนประกอบ native/runtime → ส่วนประกอบแอป → ตรวจยืนยัน → เปิดโปรแกรม
ตัวเลขเป็นขั้นตอน ไม่ใช่เปอร์เซ็นต์ข้อมูลดาวน์โหลด ผลซ่อมเก็บใน data/repair-status.json และมีตำแหน่ง log
ถ้าล้มเหลวจะระบุขั้นที่หยุดและสาเหตุ ไม่แสดงว่าซ่อมสำเร็จ ผลล่าสุดแสดงเมื่อกลับมาเปิดหน้าตรวจอีกครั้ง

## ค่า EQ ประจำเพลง
EQ → จัดการค่าเพลง: ค้นหาด้วยชื่อไฟล์หรือตำแหน่งเพลง, สำรองทั้งหมด, นำเข้าค่า และตรวจตำแหน่งไฟล์
ไฟล์สำรอง JSON รุ่น 1 ไม่เกิน 10 MB ตรวจข้อมูลครบก่อนแก้ไข หากมีค่าซ้ำเลือกเก็บเดิม/แทนที่/ยกเลิกได้
ก่อนนำเข้า ระบบเก็บสำรองค่าเดิมใน data/EQ-backups หากสำรองหรือบันทึกไม่สำเร็จจะแจ้งข้อผิดพลาด
นำเข้าไม่เปลี่ยนเสียงเพลงที่กำลังเล่น ใช้เมื่อเรียกเพลงครั้งถัดไป ไฟล์สำรองไม่ได้รวมไฟล์เพลง
การตรวจไฟล์ไม่ลบข้อมูล ไม่พบไฟล์อาจหมายถึงไดรฟ์ USB/เครือข่ายยังไม่พร้อม การตรวจไดรฟ์เครือข่ายอาจใช้เวลานาน แต่หน้าต่างยังใช้งานได้

ข้อจำกัด: รุ่นนี้พัฒนา/ตรวจบน Linux พร้อมทดสอบ UI และจำลองบางส่วน ยังไม่ได้ทดสอบ Windows จริงหรือสร้าง EXE บน Windows
