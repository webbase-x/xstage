ข้อมูลส่วนตัวและการเก็บประวัติ

ผู้เยี่ยมชมสามารถดูรายการแอปและอ่านรีวิวได้โดยไม่ต้องลงชื่อเข้าใช้ เมื่อเลือก Google Login ระบบจึงใช้บัญชี Google ผ่าน Supabase Auth เพื่อระบุผู้ใช้สำหรับการบันทึกและแก้ไขข้อมูลเฉพาะของตนเอง

ข้อมูลที่บันทึก

  • บัญชี Google ที่ผูกกับ Supabase Auth ใช้เพื่อยืนยันตัวตน
  • เมื่อเข้าสู่ระบบและกดดาวน์โหลด: ชื่อแอป เวอร์ชัน ประเภทอุปกรณ์ และวันที่กดดาวน์โหลด
  • เมื่อผู้ใช้เลือกยืนยันเอง: ประวัติว่าผู้ใช้แจ้งว่าติดตั้งแอปแล้ว (ระบบไม่ยืนยันกับระบบปฏิบัติการ)
  • คะแนนดาวและความคิดเห็นที่ส่ง: แสดงสาธารณะโดยไม่แสดงที่อยู่อีเมล

การใช้ข้อมูลและการควบคุม

ข้อมูลใช้สำหรับแสดงประวัติส่วนตัว ปรับปรุงแอป และดูข้อเสนอแนะ โดยระบบแยกสิทธิ์ฐานข้อมูลด้วย Row Level Security ผู้ใช้ทั่วไปอ่านรายการและรีวิวได้ ผู้ที่เข้าสู่ระบบเขียนรีวิวของตนได้ ผู้ดูแลที่ได้รับสิทธิ์จึงตรวจดูประวัติกิจกรรมในระบบเพื่อดูแลบริการ

เจ้าของบัญชีสามารถลบประวัติของตนจากหน้าเว็บ และลบหรือแก้ไขรีวิวของตนจากหน้ารายละเอียดแอป การลบบัญชีและข้อมูลอื่นที่เก็บในระบบยืนยันตัวตนสามารถติดต่อผู้ดูแลโครงการผ่าน ช่องทาง GitHub Issues (อย่าเปิดเผยข้อมูลส่วนตัวใน Issue สาธารณะ)

การอัปเดต

แอป Android เป็นตัวแสดงหน้าเว็บ X-Stage Apps จึงรับข้อมูลเว็บล่าสุดเมื่อเปิดใช้ผ่านอินเทอร์เน็ต การอัปเดตโค้ด Android เองยังต้องใช้ไฟล์ APK รุ่นใหม่และลายเซ็นที่ตรงกัน
