ดาวน์โหลด current.json และฐาน DB/catalog ที่มีจริง โดยไม่โหลดเพลง · หากไม่มี DB จะแจ้งข้อผิดพลาดชัดเจน

▦

ชุดสำรอง ZIP

สำรองเพลงและฐานที่อ่านได้เป็น ZIP · เมื่อไม่มี Catalog จะอ่านโฟลเดอร์จริงทั้งหมด · ตรวจ MD5

ผลดาวน์โหลดคลังออนไลน์จะเก็บในโฟลเดอร์ XStageWeb แยกจากคลังสร้างเพลงในเครื่อง ไม่เขียนทับฐานเพลง PC เดิม และไม่อัปโหลดหรือเปิดสิทธิ์สาธารณะโดยอัตโนมัติ · หาก XStageWeb มองไม่เห็น กรุณาตรวจบัญชี Google และ OAuth Client เดิมที่ใช้เผยแพร่ ห้ามเลือกสร้างคลังใหม่เพื่อแก้ปัญหาการดาวน์โหลด

บัญชี Google

ลงชื่อเข้าใช้บัญชีของตนเอง · ไม่ต้องเลือกไฟล์ JSON เมื่อแอปตั้งค่าไว้แล้ว

กำลังตรวจการตั้งค่า OAuth ของแอป…
กำลังตรวจว่า Song Studio PC ได้รับ Google Drive token แล้วหรือยัง…
ตัวเลือกขั้นสูง · ใช้ OAuth Client JSON ของตนเอง
ถ้าเลือกไฟล์ ระบบจะตรวจและคัดลอกค่าระบุตัวแอปไปเก็บในพื้นที่ส่วนตัวของ Windows เพียงครั้งเดียว · ใช้ได้กับรุ่น PC ที่อัปเดตภายหลัง
การตั้งค่า Client ID เป็นข้อมูลของแอป ไม่ใช่บัญชีผู้ใช้ · ผู้ใช้ Google แต่ละคนอนุญาตสิทธิ์ครั้งแรกด้วยตนเอง · โทเค็นเก็บแยกบัญชี Windows และเข้ารหัสด้วย DPAPI

เครื่องมือประมวลผล

กำลังตรวจ FFmpeg, FluidSynth, SoundFont…
ส่วนประกอบต้องพร้อมก่อนสร้าง Installer; งานสร้าง M4A ทำบน Local Engine ไม่ต้องให้เว็บดาวน์โหลดเครื่องมือใหม่ทุกเพลง

ประวัติการแก้ไขและตั้งค่าอัตโนมัติ

บันทึกเมื่อกดบันทึกข้อมูลเพลงหรือเปลี่ยนการตั้งค่า · คืนค่าที่ใช้ครั้งก่อนเมื่อเปิดแอปอีกครั้ง · เก็บประวัติสูงสุด 50 รายการในเครื่อง
