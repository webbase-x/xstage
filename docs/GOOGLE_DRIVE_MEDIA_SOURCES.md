# X-Stage Karaoke — เลือกโฟลเดอร์ Google Drive และสร้าง SQLite ภายหลัง

## หลักการ
คลังหลักยังคงเป็น `XStageKaraoke` ที่กำลังเลือกในหน้า Karaoke Online และฐานเล่นเพลงเพียงไฟล์เดียวคือ `XStageKaraoke/DB/songs.sqlite3`. ห้ามใช้คลัง Google Drive เดิมที่ยกเลิกแล้ว

ในหน้าต่าง **นำเข้าเพลง / SoundFont** มีตัวเลือก Google Drive 3 ประเภทที่แยกอิสระ:
- **เพลง:** โฟลเดอร์ต้นทาง XMID/XSK ที่มีอยู่บน Google Drive (รวมโฟลเดอร์ย่อย)
- **SoundFont:** โฟลเดอร์ SF2/SF3 โดยตรงหรือมีโฟลเดอร์ย่อย SF2, SF3; ตัวเล่น MIDI ใช้ตำแหน่งนี้ทันที
- **FX:** โฟลเดอร์ FX ของเวที; เมนูเสียงเอฟเฟกต์หน้าเวทีสามารถโหลด WAV, MP3, OGG, M4A ที่เข้าถึงได้ และจำกัด 10 ไฟล์ / 48 MiB ในหน่วยความจำ

การเลือกโฟลเดอร์ใช้ Google Picker พร้อมบัญชี Google ที่ล็อกอินแล้ว เก็บเฉพาะ Folder ID และชื่อใน localStorage แยกตามรหัสบัญชีและคลังที่เลือก **ไม่เก็บ OAuth token หรือเนื้อหาไฟล์ไว้ในรายการตั้งค่า** เปลี่ยนโฟลเดอร์ได้โดยไม่ย้ายหรือลบไฟล์เดิม

## วิธีใช้งานแบบสองขั้นตอน

1. เชื่อม Google และเลือกคลัง `XStageKaraoke` ที่ยังใช้งาน
2. อัปโหลดไฟล์ XMID/XSK เข้าคลังผ่านโปรแกรม โดยเลือก **อัปโหลดไฟล์อย่างเดียว** หรืออัปโหลดเข้า Google Drive ด้วยวิธีที่ต้องการ
3. ในส่วน **เลือกแหล่งข้อมูลบน Google Drive** กดเลือกโฟลเดอร์เพลงผ่าน Google Picker
4. กด **ตรวจไฟล์บน Drive และสร้าง DB/songs.sqlite3**
5. ระบบสแกนทุกโฟลเดอร์ย่อยที่แอปอ่านได้ ตรวจ SHA-256 ภายใน XMID และ MD5 ของ MIDI ภายใน ตัด MIDI ที่มีเนื้อหาเหมือนกัน และเพิ่มเฉพาะเพลงใหม่เข้าแค็ตตาล็อกเดิม
6. เมื่อการตรวจครบและผ่าน จึงสร้าง/ตรวจ SQLite และเผยแพร่ใน `DB` ครั้งเดียว โดยกลไกเดิมสำรองฐานก่อนหน้าหากมี

ปุ่ม **ยกเลิกการสร้างฐาน** หยุดการตรวจโดยไม่มีการเผยแพร่ฐานที่ยังไม่สมบูรณ์ และไม่ลบไฟล์บน Google Drive หากไม่มีเพลงใหม่ให้เผยแพร่จะไม่เขียน DB ใหม่

## ข้อจำกัดและความปลอดภัย

- โหมด **สร้าง DB จาก Drive ภายหลัง** รองรับ **XMID/XSK** ที่ตรวจสอบได้ก่อน รูปแบบ MID/NCN, MP3 และวิดีโอสามารถนำเข้าผ่านขั้นตอนนำเข้าและสร้างฐานตามปกติได้ แต่ยังไม่ถูกทำดัชนีด้วยคำสั่งสร้าง DB ภายหลัง
- ขอบเขต OAuth ปัจจุบันคือ `drive.file`: การเลือกโฟลเดอร์ผ่าน Google Picker **ไม่รับประกัน** ว่าแอปจะอ่านไฟล์ทุกไฟล์ภายในที่อัปโหลดด้วยบัญชีหรือโปรแกรมอื่นได้ ระบบตรวจสิทธิ์ก่อนจำโฟลเดอร์ หากรายการภายในไม่ปรากฏให้ตรวจสิทธิ์ของไฟล์เหล่านั้นก่อน ไม่อ้างว่าโฟลเดอร์ว่างหรือไฟล์ถูกลบ
- โปรแกรมไม่ใช้คลังที่กำหนดยกเลิก ไม่อ่าน/สแกนโฟลเดอร์ย่อยที่มี Folder ID ของคลังดังกล่าว
- ไม่ลบหรือรวมไฟล์ต้นฉบับโดยอัตโนมัติ การตรวจซ้ำใช้ MIDI **ภายใน** XMID/XSK ไม่ใช้ชื่อไฟล์หรือ MD5 ของตัวห่อเพียงอย่างเดียว
- การเผยแพร่ฐานใช้การตรวจรุ่นล่าสุด, การล็อกข้ามแท็บและการสำรองฐานเดิม จึงไม่ยอมเขียนทับฐานที่ถูกเปลี่ยนจากอีกเครื่องโดยไม่ตรวจ
- พื้นที่ FX ไม่มีการอัปโหลดอัตโนมัติ ไฟล์ที่เลือกเปิดเล่นชั่วคราวในแท็บเท่านั้น จำกัดขนาดเพื่อไม่ให้หน่วยความจำทำงานหนัก
- ไฟล์เสียง/เพลง/FX ยังเป็นข้อมูลส่วนตัวบน Google Drive; ไม่มีการเก็บ Google access token ในการตั้งค่าโฟลเดอร์

## การทำงานเมื่อสลับแท็บ

งานสร้างฐานจะไม่ถูกยกเลิกเพียงเพราะสลับแท็บ และระบบอัปเดตเว็บจะไม่รีโหลดระหว่างสร้างฐาน ผลตรวจแพ็กเกจที่ผ่านแล้วเก็บเป็น metadata ใน IndexedDB แยกบัญชี คลัง โฟลเดอร์ และ File ID/MD5/ขนาด/ชนิดไฟล์ โดยไม่เก็บเสียงหรือ OAuth token เมื่อกลับมาเปิดแท็บหลังถูกพักหรือรีโหลด ระบบทำงานเดิมต่อหลังยืนยันบัญชี โดยอ่านรายการไฟล์และฐานล่าสุดก่อนเสมอ หากไฟล์เปลี่ยนต้องตรวจใหม่ ปุ่มยกเลิกล้างงานที่รอทำต่อแต่ไม่แตะฐานเดิม Safari/iOS สามารถพัก JavaScript เมื่อสลับแอปหรือล็อกจอได้ จึงไม่รับประกันการทำงานขณะระบบปฏิบัติการระงับแท็บ การทำงานตลอดแม้ปิดแอปต้องมี worker ฝั่งเซิร์ฟเวอร์ที่ได้รับสิทธิ์ Google Drive อย่างเหมาะสม
