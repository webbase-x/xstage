นโยบายความเป็นส่วนตัว X-Stage Karaoke Online

เว็บไซต์ใช้ Google Identity Services เพื่อให้ผู้ใช้อนุญาตการเข้าถึงไฟล์ของแอปใน Google Drive บัญชีตนเอง โดยขอสิทธิ์ drive.file และข้อมูลบัญชี Google ที่จำเป็นต่อการระบุบัญชีที่เข้าสู่ระบบ

ระบบเข้าถึงเฉพาะไฟล์เพลง M4A เนื้อร้อง JSON และ Catalog ที่แอปสร้างหรือที่บัญชีอนุญาต ไม่อัปโหลดไฟล์เพลงหรือฐานข้อมูลส่วนตัวลง GitHub Pages และไม่ใช้ระบบสำรอง SQLite/คิวเพลงเดิมผ่านเว็บนี้

เว็บเก็บ Google Access Token ไว้ในหน่วยความจำของแท็บระหว่างใช้งานเท่านั้น ไม่เก็บใน Local Storage เมื่อออกจากระบบ จะล้างรายการเพลง คิว และ Blob URL ที่ดาวน์โหลดในหน้านี้ การดาวน์โหลดไฟล์เสียงและเนื้อร้องเกิดขึ้นจาก Drive ของบัญชีที่ลงชื่อเข้าใช้ผ่าน Google Drive API

ไฟล์ใน Google Drive จะยังคงอยู่จนกว่าเจ้าของจะจัดการหรือลบเอง การออกจากระบบไม่ลบไฟล์ใน Drive ผู้ใช้สามารถยกเลิกการอนุญาตแอปได้ที่ การเชื่อมต่อของบัญชี Google การใช้ข้อมูล Google API อยู่ภายใต้ Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

ติดต่อเกี่ยวกับโครงการได้ที่ GitHub Issues และไม่ควรเผยแพร่โทเค็น รหัสผ่าน หรือไฟล์ส่วนตัวใน Issue สาธารณะ

เครื่องมือเล่นเพลงบนเว็บ

เพลงโปรด ประวัติและการตั้งค่าเวทีในหน้านี้ใช้เฉพาะเซสชัน ข้อมูลคิวจะถูกดาวน์โหลดไปยังอุปกรณ์เฉพาะเมื่อผู้ใช้เลือกส่งออกเอง หน้าต่างจอร้องแยกได้รับข้อมูลเนื้อร้องจากหน้าเครื่องเล่นบนเว็บไซต์เดียวกันเท่านั้น ไม่ได้รับ Google Access Token

เมื่อผู้ใช้เลือกฟังก์ชันบันทึกไมโครโฟน เบราว์เซอร์จะขออนุญาตใช้ไมโครโฟนตามสิทธิ์ของอุปกรณ์ ข้อมูลเสียงบันทึกจะดาวน์โหลดลงเครื่องผู้ใช้เมื่อหยุด ไม่อัปโหลดไป Google Drive โดยอัตโนมัติ ส่วนเสียงเอฟเฟกต์ที่ผู้ใช้เลือกในหน้าเว็บเป็นไฟล์เฉพาะการใช้งานนั้น
